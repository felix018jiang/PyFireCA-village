这一阶段解决单层原胞的两种混淆：草地火焰够不到旧建筑的2 m受体，并不意味着墙脚可燃部位不会着火；反过来，墙脚或树下死燃料着火，也不意味着整个建筑或树冠立刻参与燃烧。新增可选的 `run-components-v3` 实验入口，保持每个部位的独立状态与预算。**这是可运行的机制实验基础，不是经过标定的冠火或建筑损毁模型。现有网页及普通 `run-v3` 不会自动切换到分层实验。**

## 1. 科学依据与不能外推的内容

[NIST GCR18-018](https://www.nist.gov/publications/structures-ignited-virginia-wui-fires-22015-22017)记录21个植被火引燃或严重损伤建筑案例，常见路径是地表叶片/枯落物蔓延至木质外饰面，部分进一步烧穿至内部。它支持“近地面燃料→特定建筑可燃部位”的路径分解；没有未受损建筑分母，不能给出普遍引燃概率，也不能据此把砖石设为可燃。

[Ritter等2023](https://research.fs.usda.gov/treesearch/66560)用空间显式火行为模型研究垂直和水平燃料连续性，结果表明低处冠层燃料与上层水平连通存在交互；高强度下仅靠冠基高/梯状燃料不能充分解释树冠消耗。它支持分离高度和水平邻接，**不是本程序的独立实验验证**，文中的强度阈值也没有直接移植为本程序参数。

[NIST WUI传播机制说明](https://www.nist.gov/el/fire/resources/hazard-mitigation-methodology-hmm/how-fire-spreads-wui)区分辐射、直接火焰接触和飞火。新增部位只涉及前两者中的已有辐射与有效接触闭合；不表示飞火影响已经覆盖。

## 2. 数据、质量和能量契约

实现位于 `src/pyfireca/village/components_v3.py`；配置为 `examples/village/vegetation_v3/components.synthetic.yml`。每个可燃地表类别可明确分成2或3个部位；未配置类别维持 `whole` 单部位。未知、域外和不燃格不新增可燃部位；不补造林下枯落物或建筑燃料。

每个部位填写：

| 字段 | 含义及约束 |
|---|---|
| `live_fraction` / `dead_fraction` | 分配到本部位的原原胞活/死燃料份额；两个字段分别在同一配方内求和为1，不是本部位的活/死比例 |
| `area_fraction` | 原覆盖面积和辐射接收面积的有效交换面积份额；同一配方求和为1 |
| `footprint_fraction` | 接触闭合中源足迹占原覆盖部分的比例；可与有效受热面积不同，垂直叠置部位可共享足迹 |
| `source_base_height_m` | 火焰柱底部相对当地地面的高度 |
| `flame_extent_m` | 有效火焰柱从底部向上延伸的长度；当前为显式固定输入 |
| `receiver_height_m` | 本部位受体相对当地地面的高度 |

以树木为例，原活/死干质量比例为0.65/0.35，合成地表部位分配活燃料0、死燃料0.3。因此它取得总干质量的 `0.35×0.3=0.105`，并继承原死燃料含水率0.15 kg/kg_dry；其余活/死燃料及各自水量留给高处部位。**这是假定既有死燃料如何分布，不是测得有30%的死燃料落在地面；真实死燃料可能仍在枝冠。**

部位干质量 `m_k = f_live,k m_live + f_dead,k m_dead`；水量分别按对应活/死份额分配，含水率由部位水量/干质量重算。部位热解比例、热值、引燃温度、比热及散热参数继承原原胞；有效受热干质量按原受热/总干质量比例分配。由此受热水量总和也与分层前一致。

本轮为不同时混改燃烧标定，按 `m_k/m_total` 同比例分配热解质量、峰值HRR、活跃燃烧面积和可释放能量，保留原增长/稳态/衰减时长。每个部位的HRR积分独立闭合。**继承原曲线时长不代表地表细燃料与树冠真实燃烧时长相同**；它是最小对照的约束，部位特定燃烧曲线仍需后续数据。

求解前按原物理原胞逐项核对总干质量、活/死干质量、活/死水量、热解质量、有效受热质量/水量、覆盖/接收/活跃面积、峰值HRR、可释放能量和曲线积分。零质量部位、超额/缺额份额、非法数值或不支持的地类编码直接报错。

`area_fraction` 是现有集总热模型内的有效面积预算，不是重建的三维叶面积、实际外墙面积或冠层覆盖率。真实垂直燃料层可重叠；需要调查几何后独立建立各层交换面积，不能把本轮面积划分当成真实分层测量。

## 3. 相邻原胞及部位之间如何传热

每个部位有独立温度、待蒸发水量、剩余燃料、引燃时间、燃烧年龄和熄灭时间，复用V3同步热内核。底部着火不会直接改变其他部位状态，也不会释放其他部位的HRR。

直接点火策略必须明确为 `lowest_receiver_only`：一个原胞点火事件只点燃该原胞最低受体部位；并列时按配置顺序。其他部位只有在实际计算的受热达到原引燃条件后才能着火。因此以树木为初始源时，旧模型点燃整格、新模型点燃地表份额，初始燃烧燃料量不同；这种比较不是纯传输机制消融。以未分层草地/灌木为初始源的主要对照避免了这一初始源差异。

接触仅允许同一原胞内不同部位，或共享边的四邻可燃原胞之间。源 `s` 与受体 `t` 必须满足：

`z_ground,s + z_base,s ≤ z_ground,t + z_receiver,t ≤ z_ground,s + z_base,s + L_flame,s`。

高处火焰不会因为源高度较大就自动向下接触地面；道路间隔和域外不会因内部数组相邻而被跳过。正的 `h(T_g−T_s)`、HRR活动份额、目标面积上限和源非辐射预算沿用第一轮修正。**一个燃烧部位向同格其他部位和邻格部位的全部接触传热共享同一个 `(1−χ_rad)Q_k` 预算**，没有每条边都重新获得完整HRR的问题。

本轮的辐射策略明确冻结为 `partition_existing_cell_edges_no_internal_radiation`。保留旧物理原胞的边权/遮挡/几何，将每条目标边权按目标部位面积份额拆分；各源部位仅发出自己的HRR，所以源辐射不会重复。**没有按部位高度重建视角因子，也没有同格内部辐射**。这使接触与部位预算的比较可解释，但会漏掉不接触条件下的垂直辐射引燃，也不足以研究强地表火跨大冠隙。高处不燃的结果不能解释为真实安全距离或真实冠火不会发生。

求解器的1×N节点数组只是存储；几何与四邻均来自原米制格网和DEM。结果明确保存节点→原胞/部位映射，不向现有二维单状态网页伪装成“整格燃烧”。

## 4. 固定实验与实际结果

实验脚本 `examples/village/vegetation_v3/audit_components.py` 在运行前冻结8场景、4方法、两步长及2秒时间稳定性容许差。4方法分别为旧单层纯辐射、旧单层接触、新部位纯辐射、新部位接触。64次合成运行结束于1200秒；另使用上一轮固定17×17高友村DEM裁剪域，600秒、纯辐射/接触×两步长4次运行，没有重新挑选点火点。

以下为0.25秒步长的部位接触结果，所有阈值保持原值：

| 场景 | 结果 |
|---|---|
| 草地→建筑 | 可燃基部47.75秒引燃，上部不燃；1200秒仅消耗建筑原胞5%的可热解燃料 |
| 灌木→建筑 | 可燃基部59.5秒引燃，上部不燃 |
| 草地→连续两格树木 | 两格地表死燃料54.0、178.83秒引燃，高处部位不燃 |
| 草地→道路→建筑 | 建筑两个部位均不引燃 |
| 极湿草地→树木 | 除直接点火的草地外无传播；5 kg/kg_dry是明显极端的数值负对照，不是典型现场含水率 |
| 低高处受体对照 | 仅改变高处部位源底/受体高度，使之进入地表火焰柱；高处部位371.5秒引燃 |
| 三层梯状燃料假设 | 地表47.25秒→梯状183秒→高处709.5秒依次引燃；全部层间分配与有效火焰高度均为显式合成假设 |

在这些以草地/灌木为源的主场景，旧单层路径和新部位纯辐射路径没有点燃目标。不能将上述时间作为实测引燃时间或现实蔓延速度。

68次运行的两步长引燃掩膜全部一致，最大首次引燃时间差0.75秒。燃料释放/辐射分配/非辐射分配账目最大绝对差约 `1.01×10⁻⁵ J`。这是源能量分配守恒检查，不是完整的气体、表面、蒸发、环境三维总能量闭合；尚无空间格宽收敛证据。

部位输出 `components.csv` 提供原胞坐标、部位、初始燃料和引燃时间；`components.final.npz` 提供独立状态、温度有效掩膜、燃料、水量和受热账目。`physical_cells.final.npz` 中 `any_component_ignited` 只表示至少一个部位点燃；另有实际消耗燃料比例，不能用前者充当整栋建筑损毁指标。烧着/烧尽部位的表面温度须按 `temperature_valid_mask` 解释。

实验入口默认上限20,000节点和500,000辐射边，先检查再展开，不绕过资源门禁运行全村。时长/点火由base-case决定。内部部位数组不兼容旧单状态网页，需明确的部位回放契约之后再接UI。

## 6. 下一步顺序与停止条件

1. **优先补足部位几何和独立燃烧曲线。**分别调查树下枯落物/冠层死枝位置、活死含水率、有效受热质量/交换面积；建筑调查实际可燃外饰面及邻接燃料。合成面积/分配的任意性是当前首要不确定性；不能仅靠画面上“火势变大”拟合。
2. **补部位辐射图，再接动态火焰几何。**高度、面积和视角因子进入同格/邻格辐射，保持单源总预算；使用有支持域的HRR/风/坡关系替代固定火焰柱。当前零内部辐射不能用于冠隙处理的真实效果排序。
3. **分层输出接入独立网页视图。**显示局部部位引燃和燃料消耗，保留高处未燃的状态，不映射为整格/整栋烧毁。先通过后端数组与网页样本一致性，再扩域。
4. **标定与验证分开。**单部位HRR/引燃→干湿燃料床→水平/垂直间隙→风坡→建筑可燃构件；保留熄灭/不传播反例，报告有效质量、h、接触份额的可辨识性。独立验证未通过前，不用本模型宣称防火线最优宽度。
5. 飞火、建筑内部传播/通风及全域空间收敛继续作为独立阶段。更低的树冠受体或额外梯状层使传播增加，仅是模型敏感性，不能据此声称梯状燃料在所有强度下都主导风险。
