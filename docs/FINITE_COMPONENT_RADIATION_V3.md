# 同格及邻格有限面辐射与可见性（2026-10-04）

`run-components-v3 --finite-radiation-config`已实现实验性完整部位辐射图：重新计算同格/邻格火焰圆柱到有限受热面的交换，显式处理其他受体与地形遮挡，替换原继承边图。它与`--internal-radiation-config`互斥，避免旧新图叠加同一份能量。普通V3及未启用此选项的部位路径继续使用原图。

## 1. 公式、遮挡及数值方法

继续使用前阶段的闭合均匀漫射火焰圆柱，发射总预算为已有`χ_rad Q`。有限面的朝向余弦、面积和距离进入双面积积分；新增可见性V(s,t)取0/1。单面接收项`max(−n_t·r̂,0)`，双面取绝对值。视角因子的标准积分、互易及遮挡背景见[NISTIR6925正式记录](https://www.nist.gov/publications/calculation-obstructed-view-factors-adaptive-integration-0)。本轮的参数值、圆柱形状和实际引燃时间并非由该几何报告标定。

受体矩形作为**静态、不透明、两侧都能挡光**的几何片；是否允许其背面热状态接收，与是否挡住到其他目标的射线分开。发射部位自身的受体不作为挡光片，因为`χ_rad Q`已定义为逃逸源包络的辐射预算； intended target不作为自身遮挡。其他接收片参与遮挡，共面且共享正面积的接收片直接拒绝，防止重复截获。边接触允许。接收片的空间边界按原物理格验证，来源/目标关系不使用1×N存储相邻关系。

地形采用每原胞一个常高度的竖直地形柱，**不是DEM双线性连续地表，也没有解决格宽收敛**。地形柱的顶/侧面覆盖射线可能经过的高度范围；道路/裸地无燃料仍可能有地形遮挡，不能把“不可燃”当作“辐射穿不过”。当启用地形可见性时，unknown/排除空间保守按全高度不透明处理；无DEM时地面为平面，不冒充实测起伏。

直接给固定Gauss节点乘0/1遮挡会出现边界采样误差。开发期复杂墙组合在最高24/32阶仍未通过，故改为**先裁出可见面积，再积分**：对每个发射积分点，一个矩形投影的线段阴影是在目标平面上的五个线性半平面的交集（一个约束交点位于射线内部，四个约束交点落在矩形内）。逐一从受体多边形减去阴影，重叠阴影不会重复扣面积；同时裁掉源法向背后的目标区。保留的凸多边形分成三角形，采用Duffy变换与Gauss积分。

火焰侧面还按每个角度的源高度转折分段：目标角点—遮挡边及遮挡角点—目标边定义的平面，与该源竖线交点成为分段位置；加上源穿越受体/遮挡平面的高度。仍积分同一火焰表面、面积及源能量，不新建发射功率。上下盖继续原圆柱积分。剩余光滑核、角向积分及其精度仍需比较，**相邻阶差并非严格误差上界，分析裁剪也不等于无限精度**。

独立`radiation_visibility_v3.py`保留连续射线与矩形/地形柱相交算法，作为另一种实现的参考。可见多边形与20,000个固定随机点的直接射线分类逐点一致；半开口面积、投影内孔、重叠阴影、单位方形解析因子/互易、源表面积与法向均有独立测试。

## 2. 能量和支持域

每源所有有限边权之和≤1，超过直接拒绝，不按行归一化或调小距离。求解器仍只对接收份额应用一次吸收率；燃料能量、初始水分、阈值、指定HRR曲线、接触及同步时钟不改。完整图的未分配辐射包括地形、未追踪背面/反射以及截断范围外等路径；**该账目不是“所有未分配辐射都逃逸到空气”**，也没有构建完整环境能量再分配。

普通草地/冠层矩形不是实测透明度。将叶片/冠层当不透明静态片可能过度遮挡，燃尽后片仍存在；关闭可见性只用于显式消融。真实冠层孔隙、非燃料墙体/建筑体积、开口、厚度导热、反射、火焰相互吸收以及燃后几何仍缺失。因此这只是声明支持域的部位模型，不能称完整WUI火灾或冠火预测。

候选按**原物理格中心距**≤配置值选取，样例4 m；实际源/面上射线长度可以大于4 m，不把此参数称为实际最长光路。截断是计算假设，尚无一般范围收敛。圆柱/接收面相交仍拒绝，不能靠正则化继续；多部位的接收面遮挡已可追踪，但未建立真实三层冠层透射模型。

新增资源上限：每发射点最大受体三角形数、每角度最大源高度段数、候选边数、核计算数及半平面顶点测试数。对每对源/受体在积分前计算实际高度分段的节点数，结合最大三角形数给出最坏上限；超额在积分前拒绝。缓存相同几何不隐式放宽资源额度。受体相交及遮挡候选用原格空间索引筛选，避免不必要的全节点两两查询。

样例积分3→6→12→24，误差容限仍相对1%、绝对10⁻⁵；三角形/高度段各32。较大的最坏工作上限只允许明确的小场景实验，不表示会执行所有最坏计算，更不表示已经完成大域性能验收。高友村289格全裁剪未在本阶段运行；不把前阶段冻结图的结果直接当新完整图的结果。
