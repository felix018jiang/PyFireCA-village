## 1. 依据与方法选择

[NISTIR 6546](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nistir6546.pdf)区分点源与有限固体火焰辐射模型，指出将辐射集中在一点的近场估算可能过于保守（高估受热）。[NIST SP1169](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.1169.pdf)给出固体火焰辐射与视角因子的关系及其验证背景。本轮不将其中液体池火的经验发射功率直接套用于植被。

[NISTIR 6925](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nistir6925.pdf)给出漫射表面之间视角因子的双面积积分、互易关系与遮挡问题。采用这一几何积分基础，将每个已有燃烧部位的 `χ_rad Q` 分布到一个有限火焰外包络表面，不通过新增发射功率放大HRR。

以上依据支持公式结构和有限几何计算，**不支持本例火焰半径、圆柱形状、部位受体形状、植被辐射分数或实际引燃时刻的现场准确性**。

## 2. 几何、公式与能量契约

燃烧源假设为闭合、均匀漫射圆柱表面，包括侧面、上盖和下盖；受体假设为水平、双面可接收辐射的正方形薄片。其面积使用已分配的 `receiver_area_m2`，边长为面积平方根。**水平薄片可作为本轮燃料床、搁板或水平可燃构件的几何假设，不能宣称已表示真实外墙、任意叶片方向、孔隙冠层或实际建筑立面。**

源半径：`R_k = cell_size × radius_fraction × sqrt(parent_coverage × component_footprint)`。

火焰底部/高度沿用部位输入，源表面积 `A_s = 2πR(L+R)`。当部位瞬时HRR为Q时，有效均匀发射功率密度为 `E_s = χ_rad Q / A_s`；因此积分发射功率仍为已有辐射预算，没有再次乘火焰发射率或增加燃料能量。

定义方向 `r̂ = (x_t−x_s)/r`，同格传递份额为：

`F_st = (1/A_s) ∫_As ∫_At max(n_s·r̂,0) |n_t·r̂| exp(−κr) / (πr²) dA_t dA_s`。

圆柱只向外发射，受体两面均可接收，所以接收余弦取绝对值；接收面积采用一面的几何面积，不因“双面”再乘2。受体的原吸收率在求解器中仅应用一次。原蒸发潜热、散热、有效受热质量、引燃温度、热解燃料量、HRR曲线和同步时钟保持。

每个新内部边分配功率 `F_st χ_rad Q`。新边与原跨格边共同检查每源权重和不超过1；剩余计入未截获辐射。**超额直接报错，不按行归一化来掩盖几何问题。**这意味着原跨格预算已占满的输入可能不能增加内部边，需要重新建立完整几何，而不是获得额外辐射能量。

同格两部位共用地面标高，平移地面不会改变相对几何；并未因此实现DEM对新跨格辐射的遮挡。假设空间透明/无反射，受体未吸收的辐射不再次参与散射；下盖向地面发出的未追踪辐射属于未截获预算，不代表真实能量全部逸散至空气。

## 3. 数值方法和拒绝条件

侧面沿高度用Gauss积分、沿圆周用4n个中点；上下盖沿半径平方用Gauss积分，受体用二维Gauss积分。一次边积分最多 `12n⁴` 个核计算，工作数组按64个发射点分批，避免全量点对数组驻留。

默认显式合成配置为：半径比例0.25、消光系数0 m⁻¹、初始阶数3、最高12、相对容许差1%、绝对容许差10⁻⁵、最坏核计算上限10⁸。半径比例是情景假设，精度/资源参数是数值选择，均没有从野火数据拟合。

积分按n、2n逐级比较，满足 `|F_2n−F_n| ≤ abs_tol + rel_tol |F_2n|` 才接受；最高阶仍不满足则报错。**相邻阶差是误差估计，不是严格误差上界。**实验另以6→12积分独立复核，并用解析平行正方形视角因子检查公式与实现。

明确拒绝以下输入：

- 受体水平面穿入另一部位火焰圆柱的高度区间。当前薄片与圆柱同轴，这意味着几何相交，不能加一个任意距离正则化值代替处理。
- 同格三个可燃部位。第三薄片可能遮挡辐射，目前没有间隔透射/遮挡模型；旧三层接触实验仍可运行，只不能同时启用本轮内部辐射。
- 积分不收敛、合法几何的有限半空间份额上限被突破，或新旧辐射源预算超额。
- 图边上限或最坏积分工作上限超额。后者在积分前检查，重复几何缓存可以加速计算，但不会隐式放宽资源门禁。

这些门禁定义模型当前支持域，不表示对应现实场景不会着火。火焰接触/穿入、高孔隙冠层、遮挡和合并火焰需要后续模型。

## 4. 实际对照及其解释

脚本 `audit_internal_radiation.py` 固定7场景×内部辐射开关×接触开关×两个步长，共56次合成运行；原高友村固定裁剪域8次；两个较细积分的热过程参考，共**66次求解**。主要输入在正式比较前保存，压力场景来自开发探索，**不是预注册发现，也不是现实林分数据**。

| 无接触加热场景 | 内部辐射关闭 | 内部辐射开启，dt=0.25 s |
|---|---|---|
| 原合成树木部位 | 高处保持300 K、未引燃 | 5秒采样的最高有效温度约311.47 K、未引燃 |
| 近距离极干压力场景 | 高处未引燃 | 高处约197.75秒引燃 |
| 仅增加压力场景的垂直间隙 | 高处未引燃 | 最高采样温度约356.98 K、未引燃 |
| 仅恢复压力场景的原含水率 | 高处未引燃 | 最高采样温度373.15 K、未引燃，蒸发吸热限制升温 |

压力场景将原死燃料的95%分配至地表部位（原死燃料占总干质量35%，故地表获得总干质量33.25%），保留总燃料、总峰值HRR、能量和原540 K引燃阈值；活/死含水率均设为0.01 kg/kg_dry，受体/上部源底高0.6 m，地表火焰高0.35 m，留下0.25 m间隙，因此没有接触边。**0.01的活燃料含水率是极端数值压力输入，不能当作常见或生理合理的活体树冠状态；原活/死标签与化学性质仍未重新建模。**远间隙对照只将高处输入改为2.5 m，湿对照只恢复原含水率，其他输入相同。

“峰值辐射足以克服阈值处散热”也不保证引燃：受热质量、蒸发水量和高通量持续时间共同决定是否在有限燃烧期间到阈值。压力场景只能证明新增辐射通道可以激活原热判据，不能用于验证冠火临界间隙。

高友村结果保持上轮的8个灌木、12个树下燃料部位、同一栋建筑中5个可燃基部原胞；高处树木/建筑部位仍均0。内部辐射开关没有增加引燃部位数量。无接触时仍仅直接点火的1个灌木节点。**没有为了获得更多燃烧数量调低阈值或增加HRR。**

两个时间步的所有引燃掩膜一致，时间差最大0.75秒。独立较细积分检查的边权均在配置容许差内；两个热过程参考的引燃掩膜一致，压力场景细积分引燃约199.5秒，比默认积分推迟1.75秒，高友村参考差0秒。不能将默认197.75秒视为精确物理预测；此差异展示几何积分精度对热引燃时刻的影响。

源燃料释放/辐射/非辐射分配账目最大绝对差约1.01×10⁻⁵ J。全仓库685项测试通过，5条既有Rasterio依赖弃用警告；本轮Python Ruff/格式和差异检查通过。新增20项测试包含解析因子、互易性、圆柱面积、上下对称、几何/精度/资源门禁、预算、吸热不引燃、无接触辐射引燃、时间步与CLI保存后复现。软件正确性和几何积分检查不等于野火精度验证。
