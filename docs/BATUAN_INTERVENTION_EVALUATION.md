# 岜团村统一评价接口与单条清理带试验

更新日期：2026年10月16日。

本页记录原24候选的纯效果历史试验，原始结果保持不变。用户随后补充非直线、多条带及占地面积效率要求，后续实现见[折线与多路径迭代优化](BATUAN_ADAPTIVE_FIREBREAK_SEARCH.md)，其默认排序为防火效果优先、完全同效时面积最小。

本阶段将村落求解器接入独立干预评价接口，使用现有岜团村影像、人工结构与合成燃料参数，对比无干预、预先指定清理带，以及有限候选中的效果最优清理带。所有带均是假设方案，不代表已经调查或建成的防火线。

用户最新要求为第一轮只看防火有效性。清理面积在结果中保留，但不参与目标函数、约束或并列方案排序。第二轮再加入经济性；现有静态规划模块的成本功能不改变本阶段的纯效果目标。

## 1 已实现的接口

| 文件 | 功能 |
|---|---|
| `planning/evaluation.py` | 世界坐标点火情景、统一结果及引擎协议 |
| `planning/engines/village.py` | 已核对的V3透明点辐射模型适配器、固定建筑保护对象、数值诊断和输入指纹 |
| `planning/interventions/clearing.py` | 米制矢量清理带、重叠合并、建筑及起火格保护、独立参数覆盖和传热图重建 |
| `planning/effectiveness.py` | 明确的纯防火效果排序，排除费用和清理面积，保留效果并列 |

调用形式为 `engine.evaluate(scenario, plan)`，返回含版本指纹、能力声明、保护对象指标、干预几何、面积记录和能量检查的结果。当前支持的干预是移除非建筑植被燃料，不接受隔离墙或未实现的飞火/动态风能力。

适配器初始化时，使用显式传热参数重新构建基础图，并与基础case逐项核对。只有匹配的透明点辐射图才能进入该适配器；有限面、遮挡或错误接线图不会被静默替换。空方案保留原参数和采样时钟，只关闭快照保留。采样时刻也影响原求解器的时间步切分，因此不能通过删掉采样时钟来声称完全复现基线。

## 2 清理带的物理含义

每条带由米制中心线与宽度定义。先计算它与有效可燃非建筑元胞的面积交叠，再同比例减少燃料、水量、有效受热质量、覆盖面积、峰值功率及可释放能量，保留燃烧曲线时间、温度阈值和材料强度参数。全部清理的格不再作为火源；部分清理格保留均匀混合的剩余燃料。

该方法不把窄带直接变成完整不燃元胞，也不解析格内真实燃料间隙。建筑格始终不清理，保护对象分母固定，起火格发生任何清理交叠都会被拒绝。重叠带按联合几何计量。清理带不成为不透明墙，重建后仍保留跨带辐射边。

已添加的机制测试覆盖：空方案逐状态复现、全格与部分清理的燃料/能量关系、跨空隙辐射边保留、建筑保护、起火格冲突、重叠面积、施工区域、结果指纹、无经济项的排序，以及隔离接触机制下的有限带端点绕行。

## 3 本轮试验协议

结果目录：`runs/research/batuan-intervention-20261016-r1`。`protocol.json`在候选求解前写入，记录输入、代码哈希、情景及排序规则；`source_snapshot/`保存实际执行源码，和Git父提交共同复现本轮试验。

- 基础case为`runs/batuan-slope-contact-20261016/case`，原始文件不修改。
- 使用南侧林木格160,151与162,151作为两个搜索情景，161,150作为留出情景，均为无风、3600秒。它们是局部压力测试，不是全年火灾概率样本，也没有覆盖所有森林大火方向。
- 搜索先在81×81格裁剪上运行；火到达裁剪边界时拒绝将其作为有效搜索结果。候选代表随后回到312×347完整网格复核。
- “建筑近邻区”暂以人工结构的20米缓冲区在格中心采样定义，“外围区”为其外部。它们是候选域代理，不是实测村界；现场边界与可实施区域到位后应替换。
- 候选为150米长的单条带，在两类区域分别改变位置、角度及5/10米宽度。有效清理范围受建筑、不燃地表和候选域限制，可能出现截断，不能直接作为连续施工线。
- 搜索的字典序目标依次为：最差情景受火民居数、平均受火民居数、平均建筑受火面积、平均受火风雨桥数、负的平均民居首次引燃前时长。清理面积不在排序中。

“最优”仅针对已列候选集合和上述模型情景，不是对村内外连续空间的全局最优声明。第一轮仍以当前V3内核评估，未将原生Rothermel/FBP山火内核及边界持续热暴露耦合记为完成。

## 5 本轮实际结果

在24个位置、方向和宽度候选中分别搜索外围与建筑近邻方案。两个训练情景用于排序，第三个起火点留出评价。原始case逐文件校验未改变；四份全图回放的实际最终计数与评价记录一致。

| 方案 | 同一起火点全图60分钟受火民居 | 全图建筑受火面积 m² | 留出情景60分钟受火民居 |
|---|---:|---:|---:|
| 无干预 | 3 | 908.28 | 2 |
| 预先指定单带 | 3 | 848.32 | 1 |
| 外围候选中效果最优带 | 0 | 0 | 0 |
| 建筑近邻候选中效果最优带 | 2 | 761.65 | 1 |

外围代表方案为`outer_proxy-r158-w10-a-30`，建筑近邻代表为`inner_proxy-r153-w10-a-30`。两者均为150米长、10米宽、相对投影东向负30度的提出走廊，实际清理部分分别约1288.27和616.91平方米。面积只记录，未参与筛选或排名；全部人工建筑和起火格避让。原始提出走廊与被裁剪后的实际作用范围均保存在结果中。

不重新选择方案，将留出情景延长到90分钟，在81×81局部域中无干预受火民居25栋、外围代表0栋、建筑近邻代表21栋；三组均未触及裁剪边界。建筑近邻带在该试验中主要延迟传播，不能把60分钟的减少解释为永久阻断。90分钟结果是局部域敏感性复核，不与60分钟全图回放混称同一条件。

本轮共52次训练评价、4次留出评价、4次完整域评价、3次延长时限评价，并另执行4次完整回放导出。全套回归1036项通过，新增入口与地理导出5项通过；已有9条依赖弃用警告。对照页从实际求解数组生成。GeoJSON以EPSG:4326导出，同时保留原米制几何和CRS，便于核查面积及重新计算。

这些结果支持继续扩大候选与情景，不能确定实地最优施工方案：尚未覆盖其他林地来火方向、风、飞火和实测燃料，20米代理分区也待真实村界和可处理位置替代。

## 6 继续开发的次序

1. 根据单带与候选搜索结果检查绕行、跨带和时间窗敏感性；数值尺度改变后复核方案排序。
2. 用调查/人工核定的村界、可治理区和村内可实施位置替换20米代理区域。
3. 接入多个林地来火方向、不同风场作用、燃料水分及必要的跨线机制，并建立持续外部暴露适配。飞火未接入时不输出强风跨线失效概率。
4. 在纯效果目标下扩展候选位置、宽度、长度和多线组合；采用缓存、局部交换和独立测试情景降低计算成本，报告最好已知值与并列集合。
5. 第二轮加入面积、建设维护或其他可解释的经济约束，形成效果与成本的比较。
