## 启动

在项目根目录运行：

```bash
.venv/bin/python scripts/start_gaoyou_core.py
```

打开 http://127.0.0.1:8851/ 。正在运行的服务无需重复启动；端口已被占用时，可使用 `--port 8852`。脚本复用已准备的完整地图和60分钟结果，默认启动复用现有 `runs/gaoyou-core-full-interactive-20261006/` 结果目录；自定义准备案例则默认保存在该案例的 `interactive/` 目录，也可用 `--output-root` 指定。终端 Ctrl+C 结束服务。

已启动的本轮服务由 CLI 运行，新结果实际存于 `runs/gaoyou-core-full-interactive-20261006/`。

如需从当前源地图重新生成独立案例与结果，必须指定一个尚不存在的输出目录：

```bash
.venv/bin/python scripts/run_gaoyou_core.py --output runs/gaoyou-core-new --end-time-s 3600
.venv/bin/python scripts/start_gaoyou_core.py --prepared runs/gaoyou-core-new
```

复现依赖本项目保留的 `runs/gaoyou-vegetation-v3/v12-gaoyou-terrain-coupled-full-domain-case` 与其空间底图资产；换到另一台机器需要一起拷贝并调整空间资产路径。不是仅克隆代码即可获得卫星地图。

## 操作

1. 使用右上角“＋/−”放大缩小；滚轮围绕指针缩放，拖动地图平移，“全图”复位。点击放大按钮时，优先围绕所选格或起火点放大。
2. 点击地图查询材质、状态、燃料比例、温度、首次点燃及燃尽时间。窄窗口在左侧显示所选格摘要；事件只在回放时刻已经发生后显示。
3. 点击“将所选格设为起火点”，填写模拟分钟数，再点击“开始新模拟”。只能选可燃格；无需手工输入每格水分。计算显示进度，完成后自动打开独立结果。
4. 使用底部播放、逐帧、速度与时间轴回放。切换状态、材质、地类、表面温度、HRR、燃料、水量、地形图层；底图和建筑轮廓可独立开关。
5. 每次新模拟均从案例的初始燃料、水分和地形重新开始，不会从当前回放的已燃尽状态继续燃烧。

HRR 指截至采样时刻的最后一个求解步内平均热释放率；恰好燃尽的采样帧可能保留该步释放的热量，后续步归零。尚未计算的表面温度显示“未计算”。建筑颜色表示等效原胞燃料状态，不能直接解释为整栋房屋结构损失。

## 计算和资源

材质初始水分采用既定固定默认值；接触受热采用现有模型，建筑接触高度 0.2 m 为低处可燃部位演示假设，辐射高度独立保留。未新增复杂物理模块或修改本轮燃烧公式。

求解器流式输出，每块4帧。网页只读取当前帧需要的分块，并限制动态字段缓存至每字段两块，避免一次加载完整村落全部时间帧。进度回调只报告模拟时间，测试确认它不改变求解结果或能量预算。

## 本轮验收

- 60分钟全村结果：累计引燃1,529格，燃尽1,464格，最后仍燃烧65格，剩余可燃燃料1,310,114.088 kg。该起火点附近尚有传播，60分钟并非全部火源已经熄灭。
- 真实浏览器：初始帧/末帧切换、局部放大、原胞查询，以及重新选择灌木190,393后进行1分钟全村重算并自动打开结果；无浏览器错误。
- 自动检查：957项全仓库测试通过，5条已有Rasterio弃用警告；分块回放校验字节长度、帧范围、缓存复用/限制及失败重试。
- 记录：`runs/gaoyou-core-full-20261006/summary.json`；完整60分钟结果位于该目录的 `run/`，初始案例位于 `case/`。

剩余的实地材质、含水率代表值和历史火灾验证属于后续校准工作，按用户约定后补。
