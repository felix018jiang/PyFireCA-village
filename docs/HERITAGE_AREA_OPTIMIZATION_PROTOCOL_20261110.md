# 核心遗产保护约束下的面积与全村火损优化

日期：2026-11-10。用户已授权继续实验，以寻找实际清理面积更小、重点遗产得到保护、全村火灾损失更少的防火线。沿用岜团和平岩现有数据、核心身份及建筑行动资格，不改写历史实验或证书。

## 决策与验收

经济性按用户定义采用实际清理面积。建筑和植被清理分别记账，总面积按物理清除区域并集核算；共享燃料在仍有保留归属时继续保留。取消栋数优先作为本轮目标，也不沿用“已有三栋可行即可排除四栋”的旧目标剪枝。

核心保护逐对象、逐情景评价。第一阶段的可测保护要求仍为规定观察期内核心屋面不引燃，同时保存热暴露；不把该结果擅自解释为所有构件无损。全村损失记录物理屋面与非屋面的引燃、燃尽、仍燃烧面积，燃料消耗，以及普通建筑受火归属的上下界。实际整栋烧毁与结构损伤资料缺失时记为未知。不得把重复标注的面积相加，或用拆除后更小的统计分母制造改善。

清理面积、建筑受火数和受火面积可能有冲突。先保存核心约束下的非支配方案及各面积预算下的最小模型损失；只有同一方案分别达到所有目标下界时，才认定存在同时最优。有限候选中的最优与全部合法候选的全局最优分别报告。搜索停止、缺失评价和不支持的传播机制均不记为保护成功。

## 第一批：先检验影响位置排序的数值差异

源：平岩B0120，复用已冻结25 m²历史点火区，新增独立火源数为0。观察3600 s；核心引燃后仍继续至终点。全部对照保留原12栋共同细化集合、全村背景、材料与能量规则。通过显式实验开关启用数值变化，不改变旧双尺度默认规则。

预设六项评价：

1. 1 m屋面，最大时间步由1 s减为0.5 s。
2. 0.5 m屋面，最大时间步由1 s减为0.5 s。
3. 0.5 m屋面，网格相位移动半格。
4. 0.5 m共同布局中仅将源B0120细化至0.25 m。
5. 0.5 m共同布局中增加B0121受体，并将它细化至0.25 m。
6. 0.5 m屋面，辐射面积求积间距由0.5 m减为0.25 m。

与历史同源1 m/0.5 m结果分别比较。输出B0120、B0121、B0119和B0035的选定时刻温度、HRR和燃料轨迹，用于识别源内扩燃、受体临界引燃和级联放大的区别。不通过调低温度或扩大火势取得预期结果；任何数值修正须先有独立机制证据并重算受影响方案。

每项在CA前进行节点与辐射边容量预检；单批上限6次新CA、10800 s累计墙钟，至少保留10 GB可用磁盘，已开始求解允许完成。源配置、源码快照、输入指纹和输出文件哈希保存，恢复不能重置预算。分阶段预算用于控制资源，不作为整个研究已经完成的标准。

## 后续按首批证据推进

1. 以实际物理清理面积生成回加、换位、两个或三个小对象替换一个大对象等候选；保留全库存合法资格，几何邻近只作排序，不声称远处方案已被排除。
2. 将岜团原三栋、平岩原五栋及新对照放入同源、共同布局、统一时长的面积与损失比较；保留所有核心失败后的传播结果。
3. 对筛选后的候选统一检查原完整设计火源、已知不利源及预先冻结的新火源。用于改进方案的火源归为设计集；最终候选冻结后另设独立确认，网格、时间检查点和多个方案不充作独立火灾样本。
4. 延长仍有传播的轨迹，明确最终损失或规定响应时长损失的口径。植被行动、风和飞火须由兼容评价器与机制验证支持，不能靠配置标签宣称已经覆盖。
5. 保存面积下界、当前可行上界、未决候选和非支配前沿。独立火灾观测、材料与建筑身份资料仍是现实预测和实际实施判断所需证据；模拟次数不能替代这些资料。

### 执行中发现与预先声明的后续范围

六次独立合成机制控制已归档于`docs/results/heritage-source-support-control-20261110.json`，复现脚本为` scripts/diagnose_heritage_source_support.py`。在16 m²屋面、相同4 m²对齐初火、相同燃料/能量、0.5 s时间步下，接触独立控制的末次点火为522.5/1008.0/1959.72 s（1/0.5/0.25 m支持）。这说明现有相邻热状态规则隐含的传播速度随支持尺度变化。材料、燃烧曲线和点火门槛没有调整。

据此，本轮将1 m与0.5 m明确作为两种有效CA支持假设分别检验；q和dt用于固定支持下的数值积分检查。不能将更细h自动当作更真实，也不通过调大热交换系数来消除差异。真正的水平传播率或固定米制火焰作用核需要独立物理依据。

全候选面积搜索拟采用0/1面积主问题和动态CA反例：每个物理屋面patch仅当全部归属被拆除才收费，已验证的失败保持条件作为可审计约束，返回最小未排除面积的下界。主问题的最优方案必须回到CA逐情景评价，主问题求解成功不等于保护成功。当前可行面积上界与未排除方案面积下界闭合，才可声明对应冻结问题的面积最优。

第一组主问题使用两处固定历史技术源。为保持所有方案同源，这两处源在该组中禁止清理，因此岜团为329个合法动作、平岩为945个；全部普通建筑的原资格清单仍保留。结论明确限定为固定技术源条件，不把该组证明扩展为全村所有随机起火分布。通过方案的全村损失在同一模型支持和观察期下比较；独立火源确认及植被联合行动另列实验，不借用该组面积证书。

两村各自预设主问题预算为48次新CA、14400 s累计墙钟、1200 s累计整数主问题求解时间；每次主问题上限60 s，面积绝对容差1e-6 m²、相对容差1e-8。中断/超限保留当前上下界与未决，恢复累计预算。
