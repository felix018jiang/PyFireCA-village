# 基础传播校核与地形接触诊断

2026-10-06。目标是区分“材质完全无法传播”“地图缺少可燃连接”和“传热路径被几何判据排除”。本轮不拟合或修改正式参数。

## 连续燃料与跨材质

用当前材质默认值、2 m原胞及正式高友村的建筑接触高度覆盖配置（材料5，0.2 m）计算7类场景；每类分别采用1、0.5、0.25 s时间步。建筑高度覆盖只影响接触，辐射受体高度保持独立，不沿用早期同时改变辐射高度的合成对照。

| 场景 | 0.25 s步长的首个邻格点燃时间 | 链首尾模型传播速度 |
|---|---:|---:|
| 连续草地，4格 | 30.50 s | 4.045 m/min |
| 连续灌木，4格 | 90.00 s | 1.417 m/min |
| 连续树木等效燃料，3格 | 267.00 s | 0.466 m/min |
| 草地→建筑等效燃料 | 90.50 s | 不适用 |
| 灌木→建筑等效燃料 | 92.00 s | 不适用 |
| 树木→建筑等效燃料 | 135.75 s | 不适用 |
| 草地→不燃格→草地 | 未点燃下游 | 不适用 |

速度按链首尾中心距离除以点燃时间差计算，是当前合成场景的模型输出，不能当作野火实测速度、二维火线速度或参数校准目标。全部21组结果的点燃结局一致；1 s与0.25 s首个邻格点燃时间差最大0.5 s，最大相对差约1.64%。质量消耗与释放热量闭合通过。这个有限检查不证明全村所有情形已数值收敛，也不证明模型与现实一致。

## 全村燃料通路

当前可燃114,321格。四邻域593个连通区，最大48,898格；八邻域369个连通区，最大70,214格。大多数已保存起火点在这个最大八邻域连通区内，但点燃范围相差很大。

例如草地159,353的100/200分钟结果均只引燃1格，而300分钟的208,230结果引燃8,063格。拓扑连通只是必要诊断信息；接触模型只使用边邻四个方向，且另有地形/高度限制。八邻域连通不代表有可行接触路径；辐射又可以跨越不燃间隙，因此连通区大小也不是引燃数量的严格上限。

输入的74,829格未辨明地表被演示补为不燃。现有基础案例已将known_mask补全，不能凭材料0区分实测道路与未知补全格；不能把全部材料0自动改成可燃。网页现显示此假设，并在选格摘要提供基于初始燃料的边邻/对角邻格数，不受当前燃尽状态影响。

## 定位159,353的接触限制

起火源为草地，火源高度0.35 m。四个边邻中三个可燃，但接触判据均不满足：

- 北侧草地的地面低约0.200 m，受体高度0.15 m，受体绝对位置相对源基底约−0.050 m。
- 西侧草地的地面低约0.333 m，受体相对源基底约−0.183 m。
- 南侧灌木地面高约0.200 m，加0.6 m受体高度后约0.800 m，超过源高度。
- 东侧为当前输入的不燃格。

当前判据要求受体代表点位于源基底至火源顶端之间。因此前两格被下边界排除，第三格被上边界排除。此处“有燃料邻格”和“存在接触通路”是不同的问题。

固定17×17局部地图、材质、水分、燃烧曲线、引燃阈值和已算好的辐射边，仅在诊断对照中忽略接触算子的地形输入：600 s原始地形引燃1格、消耗2.28 kg；接触地形平坦对照引燃11格、消耗25.08 kg。这个受控改变确认接触高度判据显著影响该起火点，不能证明平坦对照更接近现实。局部地图也没有外部火源。

下一项物理改进应针对坡地边界处的接触几何代表方式，先找依据并构建坡度方向对照；不能直接删除地形、让所有邻格强制接触，或统一放大热输入。仍需保留非辐射能量预算与未点燃受体散热。
