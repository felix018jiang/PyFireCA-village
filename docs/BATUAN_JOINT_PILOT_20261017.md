# 岜团村建筑间传播验证与村内外协同配置试验

日期：2026-10-17。研究目标是解释在传统建筑不能拆改、土地干预有限的条件下，防火投入应布置在哪里，以及这一选择随来火和空间结构如何变化。优化器服务于这个问题。本文记录第一轮机制检验和联合清理原型，结果文件另行附在文末。

## 对研究建议的取舍

建议以“村内—村外防火措施的协同配置”为论文主线。这与现有研究路线一致，值得采用。重点是检验配置的适用条件，而不是预先承诺混合配置必然胜出。

| 建议 | 本项目采用方式 |
|---|---|
| 先增强模拟可信度 | 先做真实建筑几何上的受控传播试验，检查跨间隙传播和清理是否真的有作用；程序测试与火灾实证验证分别报告 |
| 检查地形、分类和尺度 | 现有案例已保存来源与哈希；需进一步人工核查林缘和街巷，进行关键位置的细网格试验 |
| 村内外共同决策 | 在同一物理运行中应用全部清理，保留原来的各区域约束；不把两次单独模拟的减损直接相加 |
| 公平比较 | 先比较“达到相同保护目标所需清理面积”；随后补齐固定面积下的保护前沿、搜索预算收敛和多随机种子 |
| 协同不能由更大的可选范围证明 | 保留仅村外、仅村内及空方案作为联合问题的极限；与固定组合、分配扫描比较。收益、配置选择和交互作用分开解释 |
| 同时考虑村内起火与外部来火 | 本轮建筑对使用内部起火，属于机制检验；联合搜索仍以已声明的外部来火为目标。下一轮需增加完整村落内部起火情景，单独定义保护对象并排除初始起火建筑 |
| 不臆造两类起火概率 | 本轮按情景逐项约束，不解释为年风险。将来对内外起火的权重扫描，报告配置转换边界 |
| 建筑保护和可实施性 | 建筑保持不变，清理作用于可燃地面；现有20米缓冲区是代理分区，不是实测村界。真实道路、空地、保护空间与廊道连续性仍需调查 |
| 成本和水分不确定性 | 按用户约束固定水分，不增加含水率输入；暂以清理面积衡量干预，不增加货币造价模型 |
| 飞火与扑救 | 本轮固定关闭飞火，不引入扑救。解释为指定传播机制下的暴露/点燃削减，不解释为完整实战控火成功率 |
| 跨村落规则 | 岜团村用于开发和机制分析，之后增加不同形态的真实村落及独立验证，形成条件性的设置准则 |

“最小清理面积达标”与“固定面积下保护最多”是同一保护—面积前沿上的两种决策视角。本轮先实现前者；它不能替代后续完整的等面积配置实验。

## 已核实的数据与模型

基准案例为 `runs/batuan-slope-contact-20261016/case`。人工建筑轮廓来自原有标注，包括民居与风雨桥；不能据卫星影像确认每栋建筑的木材种类。

- 网格为5米。地形原始数据为 `data/local/elevation/fabdem-cache/N25E109_FABDEM_V1-2.tif`，原始采样间隔1角秒，双线性重采样到模拟网格。5米网格不意味着具备5米原生地形精度。
- 地表来自RGB及邻域推断，案例元数据明确标为未验证分类；未知类归零不等于误分消失。
- 木建筑目前使用固定的等效合成燃烧参数。以后以少数木材类型分组；没有调查或文献依据前不替建筑指定树种、不虚构参数差异。水分使用同一固定基准，不进入本轮搜索。
- 现有求解器具有热状态、辐射及近场火焰接触；清理不产生不透明墙，热辐射仍可跨越清理带。有限作用距离、点源近似和合成燃烧参数需要针对研究尺度验证。
- 对部分元胞清理采用剩余燃料的均质缩放，尚未解析元胞内部的精确空隙。几何清理面积可以精确相交统计，但并不等于亚网格传播已经得到物理解算。

## 代表性建筑对：试验目的与发现

从人工轮廓和栅格中，按2–5米、5–10米、10–20米间距及间隙可燃物分层选样；每层选择接近间距中点且优先不共用建筑的配对，不查看燃烧结果。现有数据形成5对，缺少的分层保持缺失。

每对比较仅保留建筑对、保留邻近地面、请求5米清理、请求10米清理四种条件；交换火源方向，采用1秒与0.5秒时间步，均运行90分钟。为检查源强，分别使用单元胞起火及源建筑全部屋顶元胞同时起火两种初始条件，共160项。后者是上界压力条件，不代表观测火灾。

第三栋建筑和远场燃料被停用以隔离机制，这不是清拆方案，也不是完整邻里的预测。清理带裁剪到可燃地面，所有两栋建筑的参数和间距保持原值。

**主要发现：清理地面植被不能替代近距离建筑间的防火分隔。** B0163–B0180的轮廓间距约3.50米，在测试源强下存在跨间隙引燃；请求5米和10米清理都没有阻断该路径。这为后续区分清障减燃、真实间距及实体防护提供了直接的模型内证据。

| 火源条件 | 接收建筑引燃的运行 | 首次引燃的典型结果（1秒时间步） |
|---|---:|---|
| 单元胞源 | 8/80 | B0180→B0163：341秒；四种处理相同 |
| 源屋顶全部元胞同时起火 | 16/80 | B0163→B0180：252秒；反向173秒；四种处理均未阻断 |

其余4对在当前条件下未发生接收建筑引燃，不能把这些原本不传播的对照当作清理成功。所有160项达到5400秒，未点燃非燃烧护边。80组粗/细时间步配对的引燃判定一致，首次引燃时间最大差1秒。这是数值一致性与机制检验，尚非实地校准。

对于3.50米配对，5米栅格没有独立解析狭窄间隙地面；需将其作为细网格/独立几何模型复核的优先位置。请求清理宽度不等于增加了同样宽度的建筑净距。

## 联合算法与本轮预先声明的实验

方案为 `L = (L_out, L_in)`，每个分量显式保留所在代理区域。各分量先裁剪到其合法可燃地面，再将实际清理几何取并集，只缩放一次燃料，进行一次完整火势求解。单层方案置入联合接口后必须保持相同清理范围、离散拓扑及数值等价的燃料数组和面积（热参数数组核查容差为相对/绝对1e-12，几何布尔运算允许浮点舍入）。

目标先满足全部设计情景的保护要求，再最小化清理并集面积：

    min A_clear(L_out ∪ L_in)
    subject to N_house(s, 5400s) = N_bridge(s, 5400s) = 0 for every design scenario s.

这仍是有限情景下的约束启发式搜索，没有连续全局最优保证。区域分区、清理类型和保护约束保持显式。

本轮先扫描空方案、两个单层方案及4种宽度分配，再固定另一层、用现有几何算子条件更新当前层。支持平移、方向、宽度、折点及多路径增删；联合搜索最多3条路径、每条5节点。单层和联合模式分别最多16次唯一候选请求，拒绝请求也计入预算，记录实际物理运行次数；比较的是原型流程，不宣称计算预算完全等价或搜索充分。

8项设计情景：4个外部起火位置×西南4 m/s和东南2 m/s。4项留出情景：另2个起火位置×西北3 m/s和东北3 m/s。位置和风均是声明的压力条件，不是实测概率。方案按设计情景冻结后，才读取留出结果，不依据留出结果重新选方案。

独立分配基线也扫描同样7种固定几何/宽度配置，不能把未经调节的旧方案相加作为唯一基线。最终在完整场地和搜索裁剪区域复算90分钟，核对民居/桥引燃数及是否触及边界。

首个未完成试算R1发现组合接口扩大了旧外部方案的实际清理范围，已停下并保留所有试算记录。正式R2改为显式带区域的组合方案，增加单层等价性回归检验。R1未冻结方案、未读留出结果，不纳入正式结论。

## 与近邻工作的差异及论文组织

[Nicoletta等，2026，Fire Ecology](https://link.springer.com/article/10.1186/s42408-026-00550-z)采用Burn-P3、建筑损失模型和关键节点优化；方法使用100米火灾模拟、25公顷网络单元，比较管理辖区内与整个景观的选址。其“辖区内外”不是木构村落“内部建筑群与外围”的同义词。它已说明结构保护与跨边界配置的重要性，因此本研究不能只以“考虑建筑”或“同时选内外”作贡献声明。

本研究拟推进：在保护传统建筑格局的条件下，将植被—建筑—建筑的传播和措施作用接入同一评价过程，解释不同来火与形态下的配置转换，并求解同一对象保护要求对应的土地干预。是否形成互补或冗余，由对照与独立验证回答。现阶段这些是研究目标，不是已取得的跨村落结论。

[NIST的WUI传播机制说明](https://www.nist.gov/el/fire/resources/hazard-mitigation-methodology-hmm/how-fire-spreads-wui)支持区分辐射、接触和飞火暴露，但不能据此验证本模型的具体系数。[Ortega等2024年真实防火带遭遇研究](https://link.springer.com/article/10.1186/s42408-024-00270-2)表明扑救与火焰条件会影响防火带效果，因此本轮无扑救模型的输出应围绕传播、暴露及点燃削减解释。

后续优先实验：

1. 对最窄建筑间隙做局部细网格及热暴露核验；建立实际道路/空地/林缘及不可施工区域，检查裁剪后廊道的连续性。
2. 完整村落内部起火与外部来火分开建集；固定面积比较无干预、单侧、固定比例及联合配置，扫描两类起火的权重，报告配置转换。
3. 将固定的一对内外措施组成无/外/内/内外四组，按同一情景计算交互；与等面积的规划优劣分开。交互允许为零或负，不能把更大的选择集本身称为协同机制。
4. 先用少数有依据的木材类型，再做材料参数区间敏感性；不增加用户要求暂缓的含水率研究变量。
5. 多种风向、搜索随机种子与搜索预算收敛后，扩展到形态不同的独立村落，形成条件性规则，而非单一通用安全宽度。

建议论文围绕三个结果问题组织：风险从哪里进入及扩大；同样保护要求下投入应放在哪里；这一配置在何种来火、形态和参数范围内保持有效。面向高水平期刊，新增迭代次数是求解充分性的证据之一，可迁移配置规律和经验证的模拟才是研究结论的支点。
