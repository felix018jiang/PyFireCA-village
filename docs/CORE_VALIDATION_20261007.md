## 判定边界

能量检查覆盖燃料释放与辐射/非辐射分配、辐射截获/未截获、接触转移/未转移及易受热表面吸收/未吸收；不声称完整空气/墙体/地面控制体热量闭合。燃烧/燃尽格的表面温度不求解，网页明确“未计算”；冷却验收针对尚未点燃的受热表面。

合成机制控制包含显式低建筑受热高度和提高引燃阈值，用于分离机制；它们不是高友村实测参数或整栋建筑损失模型。

局部裁剪删除外部热源/燃料，属于隔离数值比较。本轮细时间步无原胞烧到裁剪边界，但这不等于完整域等价证明。5组全村模拟均以原完整输入和默认1 s最大时间步运行，输出205帧逐项核对。

草地门槛敏感性应优先处理；不能仅通过扩大火势调参数。该敏感性控制只改接触受体高度，保留辐射高度和所有燃料、热参数，属于诊断，未写回默认案例。
