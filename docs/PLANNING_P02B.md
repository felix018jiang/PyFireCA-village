## 修正了哪些数值问题

**背景界面。** `IntegratedEdges.travel_time_s` 将长边在每个穿越的格网边界和处理边界处分段，累加 `长度/所在段 ROS`。原格网背景被明确解释为逐格常数；处理层使用真实矢量交集。源点与终点反向时，同一各向同性场的旅行时间保持互易，不再把整条边交给源格速率。它没有恢复未知的格内燃料变化，也不能把任意 provider 当作各向同性。

**方向集合和端点位置。** 图节点包含实际点火与目标、M0 障碍外侧候选顶点、M1 边界采样点，以及背景速率突变界面的候选点。构造所有节点对的合法连续直线边，再求图内最短路径。它去除了八方向的限制及点火/目标的格中心吸附；背景仍可依赖格网。两项改动共同降低了旧矩阵的误差，不能把全部收益仅归给方向修正。

**边的合法性。** 长边遇 M0 闭处理面即禁行，切点也禁行；原域排除格按闭元胞 supercover 检查，包括对角切点和沿边界行进。长边不能跳过不燃格或窄防火线。M1 正长度交集单独计时，同 profile 重叠仍按并集处理。原生产求解器的长邻域保护保持原样。

默认 `boundary_spacing_m=8`、`clearance_m=0.01`、`max_nodes=256`。这里 clearance 是障碍候选节点的外移距离，不是整个路径的施工安全距离；所有边仍检查原闭障碍。M1 速率为零时增加外侧候选节点，使有限不燃条带仍可绕过。超过节点预算或使用非恒定方向 provider 时明确报错，不静默删节点或改参数。

## 必须保留的限制

- **图内最优不是连续全局最优。** 边界与界面只有限采样，所有返回路径在已声明模型中可行，其时间可作为该模型连续最优的上界。复杂多区介质的折射点可能尚未被充分采样；没有路径只说明此图不可达，不能自动推断真实火不会到达。
- **两类端点语义不同。** 原方法用映射中心，新方法用实际点；报告保留旧映射参考与新物理参考。新算法没有生成完整栅格火线/到达场，仅返回节点、目标及路径，因此不能把耗时差直接写成等输出条件的加速比。
- **范围很窄。** 只接受静态各向同性 ROS 栅格，M1 只接受明确的 `ConstantDirectionalSpreadRate`。不支持 Rothermel 风向传播、动态天气、燃尽、热跨线、飞火、真实处理参数标定或复杂地理投影。
- **成本和目标没有变。** 仍按实际矢量并集计费，点火/目标与处理面冲突明确拒绝，目标不能从分母消失。节点外移是数值设置，不额外收费，也不能解释成实际施工扩宽。
- **大域成本未验证。** 完全节点图为 O(N²)。256 节点是显式资源上限，不是现实规模保证。论文主创新仍需文献排重与干预证据，不能将这次数值修正直接称为原创方法。
