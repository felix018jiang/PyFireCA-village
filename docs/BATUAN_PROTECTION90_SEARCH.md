# 岜团村90分钟联合保护与线形比较

2026-10-16。本轮在原60分钟迭代版本之上开展，原模拟器、24候选试验及60分钟迭代结果均保留。论文的问题定义、接近文献和准则提炼路线见[研究主线](BATUAN_PAPER_RESEARCH_MAINLINE.md)。

## 本轮要求和目标

在给定起火情景下，90分钟内民居与风雨桥都不引燃，随后尽量减少植被实际清理面积。无货币成本，也不通过降低点燃门槛来人为制造更大的防火线收益。

新增 `joint_protection_score`；原历史 `effectiveness_score` 排序不变。新模式 `joint_protection_then_area` 使用以下字典序：

1. 最差情景的引燃民居与桥总数；
2. 平均引燃结构总数；
3. 最差引燃桥数；
4. 最差引燃民居数；
5. 平均引燃建筑覆盖面积；
6. 所有情景中最早结构引燃时间取负；
7. 实际清理面积。

第一项为零等价于全部训练情景的民居和桥均不引燃。完全保护的方案之间前六项一致，直接选较小清理面积。没有可行方案时，保留未达标量和当前最好方案，不写成零引燃或全局最优。

## 相同请求上限的三类搜索

每个代理区分别运行三组独立搜索，每组96次唯一方案请求，较上一轮每区64次增加为每区288次、两区576次。请求上限包括物理/保护格冲突拒绝，不含预先过滤的越界或非法几何；有效CA评价数和耗时另行记录，因此该口径不是等墙钟时间比较。三个类别采用同一个优化器种子和同一组历史线位的确定性变换，物理计算可共享精确缓存。

| 类别 | 允许方案 | 本轮范围 |
|---|---|---|
| 单直线 | 一条、两个端点 | 调位置、方向、端点和宽度 |
| 单折线 | 一条、至少一个非共线转折，最多5节点 | 同上并调转折点、折点增删 |
| 多条带组合 | 至少2条，最多3条，每条最多5节点 | 同上并增删、重组路径 |

每条宽度2.5—30m、长度10—240m，局部搜索步长从20m降至最小2.5m。多带中每条必须贡献至少1m²其他路径未覆盖的有效清理地表，排除完全重复或全落在不可清理区的虚假第二条带。这是严格线形的对照，不强制最终推荐必须为折线或多条。

梁式候选保留与最好方案的局部模式搜索共同工作：平移、旋转、减宽/加宽、端点缩短/延长、折点移动/插入/删除及重组。每次都重新运行CA并检查数值约束。清理带保留建筑和地形，只改变允许植被的覆盖和相应燃料/水/能量量；跨带辐射不被删除。5m网格的部分清理以剩余燃料均匀缩放表示，不等同于显式解析2.5m真实隔离缝。

## 独立的小幅易引燃敏感性

原模型输入不修改。`ignition_rise_sensitivity` 生成独立副本：

`T_ign_new = T_ambient + 0.95 * (T_ign_base - T_ambient)`。

只降低可燃元胞的引燃温升5%，不改不燃地表、燃料、水分、热释放和传热。该5%为声明的假设扰动，不是校准值，也不等于引燃概率增加5%或总引燃能量降低5%。每个冻结方案及无干预都计算四个相同火源的扰动版，单独展示是否仍达到保护目标。本轮不利用扰动结果反向调整基准赢家。
