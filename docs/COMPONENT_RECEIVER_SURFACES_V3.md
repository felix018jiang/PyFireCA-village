# 部位受热面的方向与位置（2026-10-04）

已实现可选`--receiver-surfaces-config`：同格辐射受体可表示为水平/竖直矩形，显式指定朝向、水平偏移、宽高比以及单面/双面接收。面积与中心高度仍取现有部位参数，不新增燃料、改变水分、降低阈值或提高HRR。普通用户无需新增必填项；未传配置保持原水平双面正方形路径。

## 依据和数学契约

漫射辐射的双面积积分使用发射、接收法向的余弦及距离。[NISTIR6925的正式记录](https://www.nist.gov/publications/calculation-obstructed-view-factors-adaptive-integration-0)是前阶段所用视角因子/遮挡方法的来源。本阶段的意义是正确表达受体方向；不从这份几何报告推导草地、灌木或建筑实际燃烧参数。

方向从源指向受体，接收项单面为`max(−n_t·r̂,0)`、双面为`|n_t·r̂|`，一面几何面积仍只计一次。矩形`width=sqrt(A×aspect)`、`height=sqrt(A/aspect)`，不靠把“双面面积”乘2扩大能量。竖直法向为`(cosφ,sinφ,0)`，水平受体法向为`(0,0,1)`。φ从局部+x向+y逆时针，北向上米制格网的+x是东、+y是北；它不是以正北起算顺时针的地理方位角，更不是图像向下的行索引。偏移相对于原物理格中心，高度相对于当地地面。

完整矩形必须位于原胞水平边界内，且不穿到当地地面以下。圆柱相交检查针对整个连续矩形，包含边/角/切触；不能只检查中心是否在火焰高度里。相交时明确拒绝，不添加任意距离正则化。当前仍只支持同格两个可燃部位；三层遮挡未解决。

积分精度、资源预算、源辐射预算沿用前阶段门禁。各向受体份额≤1；旧同轴水平受体保留其半空间上限检查。源+旧邻格边权和仍≤1，超额报错且不归一化。不配置时原权重与求解终态数组逐项相同。

## 接口、记录与支持域

`village-receiver-surfaces-1`按地类/部位提供精确几何键，必须显式给出evidence/provenance。错拼部位即使未出现在当前地图中也拒绝；提供受体配置而没有内部辐射配置会报错，不静默忽略。样例只将建筑`upper_combustible`改为面积3.6 m²、中心高2 m、x偏移0.75 m的单面竖直受体，法向180°迎向同格中心。尺寸约1.897×1.897 m，底部约1.051 m。参数是合成墙面实验，不是实际建筑调查；不能自动给每栋建筑套同一真实朝向。

输出包括`receiver-surfaces.resolved.yml`、`receiver-surfaces.csv`以及manifest的完整配置和支持域。CSV逐节点记录方向、位置、法向和尺寸；未显式设定部位保留旧受体。回放需要重新传保存的受体配置。

**目前受体方向只影响同格辐射。**邻格辐射仍是原图，接触仍按原接收高度/共享边规则，不能把背火面同格辐射为零解释为该面不会接触热气或不会受邻格辐射。这是分阶段几何扩展，不是完整建筑受火模型。墙体厚度、导热穿透、开口、反射、实际遮挡、动态火焰、飞火和整体建筑损失均未实现。

直接点燃建筑基部时，基部→上部的辐射份额：旧水平0.08030184，迎火竖直0.07288094，背火竖直0，双面竖直0.07288094。迎火面并不必然比任何水平面受热更多；有限位置、面积和法向共同决定结果。较细12→24阶参考与默认值在预定1%/10⁻⁵差内，方向旋转等价性成立。
