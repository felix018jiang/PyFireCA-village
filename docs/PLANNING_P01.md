## 运行与产物

本地 `.venv` 已具备所需依赖。其他环境需安装项目的 `planning` extra（Shapely ≥ 2），不增加核心 NumPy/PyYAML 的强制依赖。

```bash
python -m pip install -e '.[planning]'
python examples/planning/single_line.py --output runs/planning-p01-new
```

输出目录必须不存在；重复使用直接报错，已有文件保持原样。每次输出：

| 文件 | 内容 |
|---|---|
| `study.resolved.json` | 计算前冻结的格网、布局、点火、目标、证据、时限、容差及能力表 |
| `evaluations.json` | 每布局到达时间、有限时限暴露、成对收益、面积/成本和诊断 |
| `*.arrival.npy` | 完整静态图到达时间，图不可达为正无穷 |
| `treatments.local-metre.json` | 明确局部米制坐标的处理面；不是地理 GeoJSON |
| `provenance.json` | Python/NumPy/Shapely、相关源码 SHA256、HEAD 和 dirty 状态 |

JSON 到达时间为 `null` 时，必须结合 `target_graph_unreachable=true` 解读；不能把它当作零延迟。`boundary_contact_at_horizon=true` 提示火传播已触及试验域边缘，不能从截断域推断外部绕行或安全。示例记录复现输入，不提供通用配置加载器或断点续跑。

## 已冻结的模型语义

- `PlanningGrid` 只接受 north-up 的 `local_metre` 坐标，宽度以米定义，独立于格宽。元胞中心由西/北边界及格宽定位；点映射西/北边界包含、东/南边界不包含。EPSG/投影和旋转格网尚不支持。
- `Treatment` 是正宽度平头直线条带。整个处理面须在矩形建设范围内，超出明确拒绝，不能静默裁剪成本。尚无道路可达性、坡度施工限制或真实土地许可。
- M0 理想不燃带：闭处理面与传播边任意相交即禁行，切点也阻断；处理面覆盖的元胞中心从可燃图排除。这仅表示图传播阻隔，不代表热屏障。
- M1 处理后 ROS：正长度的边—处理面交集分别计时，包括沿其边界行进；孤立切点不增加旅行时间。对于边长 `d` 和不重叠交段 `l_k`，`t=(d−Σl_k)/R_background + Σ(l_k/R_k)`，再返回等效边 ROS `d/t`。原背景及各 profile 的 ROS 取源元胞、该边方向，不是已验证的异质子格燃料积分。
- 同 profile 面按并集计成本及旅行长度；不同 profile 即使仅接触也拒绝，避免未经定义的混合/边界优先级。原输入域非可燃角点禁止对角穿过，这一研究规则与生产求解器在障碍域上的默认语义不同；完整可燃域的无干预结果与现有求解器一致。
- 点火及固定受益目标的实际点和映射中心均不得落在任何处理面中；冲突明确报错，不移动点火、不删除目标。目标权重及分母不因布局改变。
- 静态求解器完成全图最早到达求解，再单独计算固定时限暴露。支持延迟多点火，不支持有限燃尽、动态天气、热跨线、随机失效或飞火。长邻域继续由既有求解器拒绝；未知构造参数报错。
- `evaluate_pair` 在相同格网、背景、原始可燃域、点火、目标及时限下重跑无处理/处理两个布局，没有随机数或缓存。延迟指标为 `min(A_plan,T)−min(A_baseline,T)`；完整到达时间也保留，不能用截尾延迟替代不可达性。

`Evidence(kind, source, applicability)` 记录参数的 `synthetic`、`model_derived` 或 `measured` 来源标签；填写标签不自动完成校准或验证。现有 Rothermel provider 可以作为 M1 输入；测试中 FM1 与 FM2 是分别计算的数值 profile，不是经验处理处方，也不保证处理后一定降低 ROS。

## 首轮结果及其研究含义

固定 9×11、10 m 格网，背景 1 m/s、M1 处理区 0.25 m/s，点火 `(5,45)`、目标 `(105,45)`、T=105 s。所有参数都是预先声明的合成假设。

| 布局 | 到达时间（s） | 处理面积（m²） | T 内暴露权重 |
|---|---:|---:|---:|
| 无处理 | 100 | 0 | 1 |
| M1 宽 0.02 m | 100.06 | 1.8 | 1 |
| M1 宽 2 m | 106 | 180 | 0 |
| M1 宽 4 m | 112 | 360 | 0 |
| M1 宽 8 m | 124 | 720 | 0 |
| 完整 M0，宽 0.02/2/4/8 m | 图不可达 | 1.8/180/360/720 | 0 |
| 上半条或下半条 M0，各宽 2 m | 108.2843，可绕过 | 90 | 0 |
| 连接上下半条 M0，宽 2 m | 图不可达 | 180 | 0 |

完整条带长 90 m。M1 手算为 `100−w+w/0.25=100+3w`；有限 M0 的绕行结果依赖当前格网与闭边界规则，尚未通过连续几何参考验证。两次独立输出的 study、评价、局部几何及 12 个到达数组逐字节一致。

这里有两个重要反例。第一，M0 完整条带在任意测试正宽度都切断，因此该机制下不应制造“加宽提升阻断率”的结果。第二，T=105 s 下半条与完整条带都显示零暴露，但前者仍可绕过；改变时限就可能改变规划排序。首轮不比较最优方案，也不将几何连接效果提升为未经排重的新颖性声明。
