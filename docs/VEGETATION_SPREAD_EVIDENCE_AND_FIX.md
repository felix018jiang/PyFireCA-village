研究支持“补齐热输运机制”，并不支持先将所有引燃温度降低或将辐射份额任意调大。上述证据确认机制和输入重要性；没有提供本地全部材料参数的成套标定。

## 2. 当前方程的合理部分与缺口

当前释放热量采用增长/稳定/衰减曲线：增长段是平方增长，衰减段线性。总积分为

`E_curve = Q_peak × (t_growth/3 + t_steady + t_decay/2)`。

V3 要求其与 `m_pyrolysable × ΔH_c` 闭合，并逐时间区间积分与扣减干燃料。这个守恒约束保留；不能只抬高峰值而保留全部时长，否则创造额外能量。物种与含水状态对峰值和曲线形状的影响尚未标定，所以它只是约化源模型。

原受体表面热平衡是

`q_net = α q_rad − h_air(T_s−T_air) − εσ(T_s⁴−T_air⁴) − k_b(T_s−T_air)`。

其温升、不可逆水分蒸发、有限燃料和同步提交是合理的约化数值框架。**但是 `solver_v3.py` 原先传入的对流增益恒为零**；非辐射释热没有直接给邻格加热。点源辐射又以有效三维距离的平方衰减，在近场完整火焰面、细燃料和建筑基部处缺少几何细节。

当前只加热 `effective_heated_dry_mass` 及其对应水分，不是要求整株树或整个元胞所有水分先蒸发；但这个均匀有效层仍需校准，不能替代活体叶片、多孔燃料床与表面/内部温度分布。树木单层等效和建筑单个2 m受体高度也是重要限制。

### 独立峰值上界诊断

保持原 `profiles.synthetic.yml`，一个同类源与受体中心距2 m，近场正则0.5 m，无风、无遮挡、环境300 K。把源无限维持在峰值，比较吸收辐射与受体在原引燃温度的损失；这已比原有限燃烧曲线更有利于引燃。

| 同类植被 | 吸收辐射峰值 W/m² | 引燃温度处散热 W/m² | 孤立峰值能否维持到阈值 |
|---|---:|---:|---|
| 草地 | 2,291 | 5,376 | 否 |
| 灌木 | 6,228 | 6,288 | 否 |
| 林下枯落物 | 2,061 | 5,559 | 否 |
| 树木等效 | 5,635 | 8,006 | 否 |

计算脚本独立以平衡损失的单调根给出温度上界。它说明当前特定参数的单源辐射路径存在结构性传播瓶颈；不能推广为现实植被不会传播。多个燃烧元胞、不同受体/间距或风况可能改变结论。灌木接近阈值，参数不确定性尤其不能忽略。

## 3. 已实现的新传热闭合

新增 `flame_contact_v3.py`。保持辐射独立，引入有效火焰接触候选：只考虑共享边的四邻格，双方均须已解析且可燃；不跨越一个不燃/排除格、不经过对角角点。受体绝对高度必须处于源的有效火焰柱内，地形高程确实进入该判断。

候选接触份额为 `f_ij = f_config × coverage_i × min(1, Q_i/Q_peak,i)`。最后因面积与能量限制还会缩小。覆盖按均匀混合假设解释，不能从面积比例反推出真实接触几何。接触与火焰强度同时减弱；零输出和燃尽源不给热。

`h_flame`按覆盖地表面积归一，是有效系数；不能直接拿单片叶子的表面换热系数代入，也不能把整格覆盖面积当成已重建的真实叶/墙面积。

每条边的未限额需求为

`P*_ij = A_covered,j × f_ij × h_flame × max(T_g−T_j, 0)`。

多个源的接触份额先按目标约束，使 `Σ_i f_ij ≤ 1`，不把同一受体面积重复当成多个完整表面。再按源限制取热：

`P_available,i = (1−χ_rad,i) Q_i`，

`λ_i = min(1, P_available,i / Σ_j P*_ij)`，

`P_ij = λ_i P*_ij`，同时将其接触份额乘 `λ_i`。

更新热平衡为

`q_net = α q_rad + Σ_i P_ij/A_covered,j − (1−f_contact,j)h_air(T_j−T_air) − εσ(T_j⁴−T_air⁴) − k_b(T_j−T_air)`。

这样，处于热气流中的那部分不同时按环境空气完全冷却；直接对流不再次乘辐射吸收率。分配后的对流热来自原非辐射通道，未分配部分单列，而不是再给每格凭空加一个固定热通量。全部边使用旧时间步源/受体状态，新增燃烧格不在同一步继续点燃第三格。热稳定时间步上界包含新增换热系数。

**这是可检验的有效近场闭合，不是文献给出的完整野火传播定律。** 当前只取正加热，不解气体温度、卷吸和冷却的双向耦合；强度限额也不是 CFD 能量方程。几何不含动态风/火焰倾斜、实际冠层空隙和 HRR 决定的火焰长度。本轮参数 `T_g=1100 K, h=50 W/(m²·K), f=0.5` 是明示合成敏感性起点，未声称从上述实验拟合；最大格宽2 m是本例配置范围，不是科学上通用的分辨率阈值。

### 同时修复的两个实现缺陷

- V2/V3 的整数环境温度会生成整数温度数组，随后丢弃小于1 K的增温。现强制 float64，并新增整数/浮点输入等价检查。文件案例加载会将温度转为浮点，所以这个缺陷不自动解释既有网页结果。
- V3 辐射偏移超过小域行列数时，Python 负切片会形成不匹配数组或潜在错误配对；现在排除没有任何合法源/目标对的偏移。一般大域不改变有效配对。

## 4. 实际验收结果

### 相同原材质参数的机制消融

冻结10个场景、两种机制、0.5/0.25 s两时间步、时长1200 s，共40次。除明确的高湿对照和建筑基部受体高度对照，原材质、引燃温度、HRR及燃料不改。四类连续五格植被链，旧模型各只有直接起火的1格，新模型均传播至5格。

0.25 s结果中：草地/灌木/林下/树木的第五格首次引燃约117.75/334/255.25/994.5 s。**这些时间是合成情景结果，不是实测蔓延速度或推荐参数。** 两步长全部引燃格数一致，最大引燃时间差0.25 s；非辐射释热=接触转移+未转移的能量账目闭合。没有空间分辨率收敛或实验传播率验收。

建筑对照保持原热惯性、水分和520 K阈值，仅“暴露基部”场景明确将受体从2 m降为0.2 m：草地/灌木能引燃这一合成可燃受体，旧辐射路径不能；草地无法接触2 m高受体时仍不引燃。原树木等效源可引燃2 m高受体。**这里表示一个建筑可燃元胞引燃，不代表整栋建筑被毁；不能将所有建筑受体都降至0.2 m。**

一个不燃道路格隔开草地，以及人为极高含水率草地，对照均仍只有直接点火格。湿对照不是绿草通用含水参数；仅检查模型没有删除潜热约束。

正式机制消融运行保存在 `runs/vegetation-spread-audit-20261004-f/` 和 `...-g/`；历史 a/b 是开发失败记录，c保留整数截断造成的步长差异，d/e保留中间修复后的成功记录。研究输入先写入 `study.resolved.json`；结果、峰值审计、计时及源码快照分开保存。

### 现有高友村 DEM 案例局部消融

从现有 V12 全域案例裁出289格，冻结全域起火点 `(191,390)`、600 s、0.5/0.25 s步长；原起火点来自早期植被前沿试验的第一个点，在两模型比较前已指定。保留原 DEM、RGB 假设材质、HRR、湿度和建筑标签，只有传热机制改变。

旧路径两步长均1格起火；新路径两步长均8格（灌木）起火，建筑引燃均0。引燃掩膜相同，已引燃项最大时间差0.25 s。结果表明机制已接入真实工作流，也表明不能仅因加入对流就保证建筑引燃：这个起火点的邻近树木/建筑2 m受体高于1.2 m有效灌木火焰柱，仍缺更完整的火焰与受体部位表示。

## 6. 下一阶段应怎样开发

1. **先改善受体与燃料层表示。** 地表枯落物/细死燃料、灌木、梯状燃料与树冠分别具有受热质量、水分和燃烧源。建筑至少区分可燃基部、外墙/檐口/屋面；砖石混凝土保持不燃，仅其可燃附属构件引燃。不要用统一高度或整栋燃料质量代替所有部位。
2. **将火焰几何与强度、风、坡联系起来。** 在W01已有取风接口基础上接W02；分别检验静态/时变风、火焰倾斜与近场接触，不先把风速乘到引燃概率。草地线火、单株灌木和树冠不是相同源，不能未经适用条件检验混用一条火焰长度相关式。新增长距离/倾斜接触前须有阻隔和能量检查。
3. **按实验顺序标定。** 单材质点火/HRR/受热温升→干/湿燃料床传播→风坡下跨格→植被到不同建筑部位；同时检验不传播与熄灭情景。测定细燃料负荷、死/活组分、含水率、粒径/SAV及HRR曲线；建筑需受体厚度与引燃热流—时间实验。用独立试验验证，保留热惯性、h、接触份额之间的可辨识性问题。
4. **再接飞火并单独验证。** 产额、尺寸、存活/沉降与着陆后引燃要有证据，不能靠新起火点概率补足一个物理缺项。最后才做全域性能和空间格宽收敛。现有近场闭合没有解决空间尺度依赖，不能据两步长一致宣布网格无关。

本轮不取消水分、不提高辐射分数、不降低原引燃温度，也不把合成火焰参数标记成实测。后续判断标准应是“相同可测输入下能否同时解释传播、熄灭和建筑部位差异”，而不是图上是否烧得更快。
