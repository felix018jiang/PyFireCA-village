# 基础CA材质修正与独立重算

网页：http://127.0.0.1:8853/ 。本功能只调整已有材质输入，不增加燃烧或传播公式。

## 使用

1. 点击全村地图中的域内原胞。
2. 在“材质修正草稿”选择已有材质，填写照片编号、调查记录或明确的试验假设，保存。
3. 青色框及选格说明显示待应用建议。可撤销最近一次修正，撤销也保留日志。
4. 勾选“将修正草稿用于新模拟”。可将修正后的可燃格设为起火点，选择时长后开始。
5. 系统验证原传热连接、更新参数并重建连接，另存案例和回放。历史列表标记材质修正格数。
6. 修正结果仅供回放；返回基础案例继续修改和重算，避免混用基础与修正参数。

原回放仍显示原材质和燃烧状态；不把草稿颜色当成求解结果。来源码3表示人工建议，未实测。草稿不会因一次模拟自动清空，重复重算可使用同一修正版本。

## 参数与限制

修正沿用原格覆盖率（不自动推测新覆盖率），水分来自目标材质现有参数。质量、面积、功率、能量按覆盖率缩放；比热、温度、几何高度、比例及燃烧阶段时间沿用目标材质。目标材质必须在基础案例已有且各原胞单位覆盖率参数一致，否则拒绝自动选取。原格覆盖率为零也拒绝；此时需要先提供覆盖率依据。

建筑轮廓/标注不随材质修改生成或删除；将一格改成建筑等效燃料只改变燃料类别，不代表发现新建筑，也不是外墙或屋顶材料的精细调查录入。

当前传热重建限静风、透明路径、点辐射几何，保留已有接触配置和DEM。高友村启动脚本从与案例元数据哈希匹配的case.snapshot.yml读取原配置；每次应用先重建基础连接并与原source/target/weight逐项完全一致，再重建新连接。配置缺失、旧连接不匹配或材质参数不明确时不应用，原案例保留。资源上限600万边/2048MB；超限明确失败。

每份草稿最多500次未撤销单格修正。基准全部npy与manifest哈希用作文件名隔离，日志保存于交互输出目录material-drafts，包含前后材质、依据、时间、撤销目标；HTTP修改带版本检查，模拟期间拒绝修改。原始案例和历史结果不变。
