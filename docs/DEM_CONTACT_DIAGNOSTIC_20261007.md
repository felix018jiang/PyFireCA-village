# DEM与接触高度边界诊断（2026-10-07）

## 结论

当前草地传播对亚毫米高度变化的敏感性已复现。直接原因是默认点受体
采用二值几何门禁：代表点在源地面至火焰柱顶之间，接触权重为1，否则为0。
微小高度变化会删除或增加接触边，进而改变传播路径。float32量化在本例的
柱顶边界附近足以影响判定；但仅提高计算精度不能解决点受体模型的不连续性。

这不是可以根据DEM认定的真实传播边界。本轮不修改求解器、默认参数或原始案例。

## 数据来源与精度

实际使用的 `data/local/elevation/gaoyou-v01-aligned-elevation-2m.tif` 标签为
`source_product: ASTER GDEM 30M`、`resampling: bilinear`、`dtype: float32`。
其整幅高程与当前完整村落案例逐项相同，并非其他目录里的FABDEM候选。
2 m是重采样后网格间隔，不是新增的2 m实测地形信息。现有数据没有提供本地
垂直误差或相邻格相对高差误差，不能自行指定这些误差的数值。

起火格147,266高程527.6362915039062 m，该量级float32相邻可表示数的间隔为
0.00006103515625 m，即0.061035毫米。该间隔是数字存储分辨率，不是地形测量精度。
案例加载后已使用float64，float32量化造成的信息损失不会随类型转换恢复。

## 起火格几何

草地源柱高0.35 m，受体点高0.15 m，火焰源底直接放在本格DEM地面。

| 方向 | 邻格高程减源格高程 | 受体相对源柱的位置 | 默认接触 |
|---|---:|---|---|
| 上、左 | +0.20001220703125 m | 超过柱顶0.00001220703125 m（0.012207毫米） | 无 |
| 下、右 | −0.199951171875 m | 低于柱底0.049951171875 m（约5厘米） | 无 |

四邻均为可燃草地。上坡门禁处于小于一个float32存储间隔的边界附近；下坡
阻断则是约5厘米的几何间隙，不能把它也解释成机器舍入。两个问题都来自用
地面起始的固定火焰柱去判断一个无厚度受体点，且不会随时间步减小自动消失。

全村float64高程共同减500 m后，接触图逐项相同；局部模拟仍为1格。
这排除了本次结果由大绝对高程在float64运算中的消去误差主导的解释。

## 接触单机制对照

冻结此前验收草地点的41×41裁剪、起火点、20分钟时间窗、燃料与预计算辐射边。
地形扰动只影响接触门禁，故不是地形改变后的完整物理场景。采用固定随机种子
20261007的均匀噪声场及其反号，不属于统计不确定性估计。

| 草地受体高度降低0.01毫米 | 0 | 1 |
| 草地受体高度降低0.1毫米 | 2 | 11 |
| 草地受体高度降低1毫米 | 2 | 11 |
| DEM加固定噪声，幅度不超过0.1毫米 | 2 | 3 |

| DEM加固定噪声，幅度不超过1毫米或1厘米 | 2 | 3 |
| 上述噪声反号 | 0 | 1 |

取整不是推荐修复：它只是另一种足以改变门禁的扰动。0.1毫米薄带同样不是
物理合理参数的证据，只用于展示点判据的退化行为。

±15厘米候选在同一固定噪声场的正负0.1毫米、1毫米和1厘米共6组扰动下均为
23格，出边均为4。这支持其在本案例微扰范围内的稳定性，但不证明其经验有效性、
所有点火时刻相同或全村预测更准确。该候选仍保留原非辐射源预算限制。

三组对照另外以0.25 s复验：降低0.1毫米仍11格、增加0.01毫米仍1格、
±15厘米候选仍23格，与1 s一致。因此缩小时间步不能消除本次几何敏感性。
共28组模拟，燃料、水量、燃尽HRR及能量分配检查全部通过；最大能量闭合绝对
误差约4.18×10⁻⁶ J，在既定容差内。

## 全村影响范围

完整图含411682对可燃有向四邻，其中159796对为草地—草地。
距离点门禁边界不超过0.1毫米的有向对有5238对，其中草地—草地2213对；
不超过1厘米的有14108对。这里边界距离按相对高差计算，是几何诊断量。

草地受体高度降低0.1毫米，改变1786个接触边槽，总有向接触边从236533增至
238249；提高0.1毫米则改变433个边槽，总边数降至236100。增加/删除可以同时
发生，边槽变化数不等于边数净变化。

## 后续处理

优先建立有依据的有限有效受体范围或连续接触闭合，并在真实坡度保留的前提下
检查几何微扰稳定性。不将微小数值容差当作DEM测量误差，不把DEM取整或平坦化
作为正式修复。有限带已有代码可供独立对照，但15厘米仍是合成参数，暂不升级默认。
后续需要覆盖更多起火点、坡度和材质组合，同时验证热量预算及点燃时间稳定性。
