# W02-d/e：地形体积门禁与动态辐射的步内积分

本阶段实现 `flame_terrain_v3.py` 和 `radiation_time_v3.py`，并以独立数值实验串联 W01 风、瞬时 HRR、倾斜有限面、地形门禁和时间积分。**未更新 CA 温度、燃料、引燃状态或接触传热；现有网页传播行为保持。**

## 地形体积检查

闭合倾斜圆柱与有限箱体的相交判定包含两部分：箱体六个面与圆柱的连续相交，以及圆柱基点在箱体内。两者合用可以检出完全包含，不能只查表面穿越。宽阶段使用圆柱的精确轴向/径向支撑边界；AABB 相交只筛选候选，不直接断定实体相交。

地形按既有 `(xmin,xmax,ymin,ymax,elevation,excluded)` 契约解释。普通地形柱体向下延伸；excluded 柱体在所有高度不透明。实现将上下人工边界放到整个圆柱外部，不会遗漏高于 DEM 的 excluded 空间。正穿透判断对有限边界按显式长度容差收缩，默认1e-9 m；容差内接触/穿透未分辨、允许通过。竖直火焰可以底面贴地。此容差不是改变几何的物理截断。容差须大于旧矩形1e-12 m接触容差，小于格宽的一半。

`oriented_segmented_cylinder`可接收 `terrain_cells`，在生成积分点前拒绝穿透。默认空列表保持旧调用；实际接图必须提供完整候选地形，不能把没有传地形解释为地形已验证。资源上限默认10,000候选格。

一个关键失败模式已被验证：基部在地面的闭合圆柱直接刚体倾斜，底面部分必然进入地下，其最低点为 `z_base - r*sin(theta)`。因此轴诊断通过不代表可用于贴地有限面。模块不自动抬高、不静默裁掉地下源面；这种失败保留。需要另行制定与验证近地火焰包络及地形裁剪策略。独立联测采用明确的1 m抬高合成源，仅用于数值契约验证，不能冒充草地火焰标定。

## 时间积分与源预算

`integrate_dynamic_radiation`接收固定候选边和回调 `evaluate(t) -> (Q_rad[node], F[edge])`。在每个查询时刻验证有限、非负及逐源 `sum(F)<=1`，不归一化。积分的是 `Q_rad(t)*F(t)`，并分别积累源辐射能量、各边/目标能量、未分配源能量。未分配部分可能包含地形吸收、截断、未追踪面，不能全部称作逸散。

一个解析对照：`Q_rad=t²`、`F=t/20`、t∈[0,10]时，正确受体能量125 J；使用平均源功率乘末步份额得到166.67 J，高估约33.3%。因此动态几何不能直接乘已有末步平均 HRR。

每个时间面板使用3→6→12→24阶 Gauss 对照；逐边、逐源及未分配能量分别验收，避免总目标量掩盖小边误差。不收敛时局部二分，默认最多8层、256个尝试面板和10,000回调次数。绝对容差按面板时长比例分配，接受面板的累计估计误差不随细分人为放大。检查记录接受面板、阶数、尝试数和回调次数；数组只读。累计源预算闭合单独核查。误差为阶次差估计，不是严格误差上界。

必须显式提供已知的风节点、点火、燃烧曲线分段和燃尽边界；自动细分不能替代已知断点。回调还须自行验证空间几何、相交、遮挡和空间积分。时间积分器不能证明两个查询时刻之间任意未知尖峰的几何有效性，也不自动保证源图截断收敛。

## 联测及保留的失败

运行：

```sh
.venv/bin/python examples/village/vegetation_v3/audit_dynamic_radiation.py \
  --output runs/dynamic-radiation-audit-example
```

初版联测在空间6阶、时间最大24阶/相对容差1e-4时触发时间不收敛，记录保存在 `runs/dynamic-radiation-development-failure-20261005.json`。检查发现积分坐标基曾在轴东分量0.9处切换，已改用世界竖直到轴向的最短旋转，在物理上半球连续；近反向极点使用备用坐标基，但 AGA 火焰轴不进入该分支。修正后仍有不收敛，提示不能把第一次失败全部归因于坐标基。AGA 倾斜/竖直分支及其他有限阶几何非光滑性需局部时间细分；新增后在原容差下联测通过，没有直接放宽容差。

正式联测 a/b 保存源码快照、输入假设及每个积分查询的份额/功率。转向风含5 s节点，规定HRR按 t²增长，源峰值1 MW、辐射比例0.35、r=0.2 m、L=2 m、基部1 m均为 synthetic。受体为独立单侧竖直矩形；地形平坦，无其他遮挡。

- 源辐射能量1,166,666.67 J。
- 6阶空间积分受体能量24,985.79056 J；12阶24,988.31982 J，相差约0.01012%。
- 整段与按5 s拆分结果一致，每组282次回调；最大闭合误差约2.33e-10 J。
- 12阶竖直对照25,053.14874 J；本转向例中倾斜结果略低，不能宣称“加风必然增强传播”。
- 贴地45°旋转源被地形门禁拒绝。

这个单例不是整体时间步、空间范围或野火真实性验收；源间遮挡/相交、多受体图、复杂地形、接触传热、局部火焰包络和真实数据标定仍待完成。下一阶段先解决近地源几何及源间可见性，再将步内辐射能量接到热状态更新，而不是提前发布风耦合火势。
