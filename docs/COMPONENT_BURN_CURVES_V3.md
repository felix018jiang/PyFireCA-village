# 部位独立燃烧曲线：能量闭合、功率门禁与固定消融

更新：2026-10-04。当前阶段在已有部位独立状态、近场接触及同格有限面辐射之上，增加可选部位HRR时钟。**软件功能及合成敏感性检查已完成；真实植物/建筑燃烧参数尚未标定。**无新配置时保持原曲线与传播计算。旧单状态网页尚不读取部位结果，不能把CLI新功能当作网页已经更新。

## 1. 证据支持什么，不支持什么

[NIST TN2314（2025）](https://www.nist.gov/publications/global-burning-properties-little-bluestem-excelsior-and-douglas-fir)用耗氧量热法测量小蓝茎草、木丝和花旗松的时变HRR、质量损失及辐射。报告发现峰值HRR/初始质量与干基含水率有关，花旗松辐射比例随含水率变化。它支持“燃烧曲线应按燃料及状态区分、需要时序测量”的方向；不提供本项目树下/建筑基部的通用曲线，也没有标定本次合成参数。我们没有将其含水率经验关系直接移植到所有地类。

[Butler等松针床风洞实验](https://research.fs.usda.gov/treesearch/66934)在0–27 m/s风速范围报告约26 s平均火焰驻留时间，高风速下约20 s下限趋势。试验对象是浅松针床；**火锋在一个位置的火焰驻留时间，不等于原胞全部燃料的HRR增长、稳定、衰减时间之和，更不等于包含阴燃的燃尽时间。**不能据此给所有草地、灌木和树木统一设置26 s。

因此，旧的单曲线是粗略的指定HRR模型，能量守恒合理，但分层以后各部位仍继承整棵等效树木/整块建筑的同一时钟，不能解释细燃料、上部燃料与建筑局部的不同过程。本次解决“能够独立配置与审计”，没有宣称三段解析形状已经成为真实燃烧定律。

## 2. 方程与实施契约

每部位的原燃料能量预算为

\[
E_b=m_{\mathrm{pyro},b}H_b.
\]

沿用原内核的二次增长、恒定稳定段、线性衰减：设燃烧年龄为a、增长g、稳定s、衰减d，则

\[
Q_b(a)=Q_{p,b}\begin{cases}
(a/g)^2,&0\le a<g,\\
1,&g\le a<g+s,\\
1-(a-g-s)/d,&g+s\le a<g+s+d,\\
0,&\text{其他}.
\end{cases}
\]

显式给出g、s、d后，以原燃料预算反算峰值：

\[
Q_{p,b}=\frac{E_b}{g/3+s+d/2},\qquad
q_{p,b}^{\prime\prime}=\frac{Q_{p,b}}{A_{\mathrm{active},b}}.
\]

对曲线积分严格闭合至原预算。各部位燃料、活/死水分、有效受热质量、受体面积、活动面积、引燃温度、辐射比例及几何保持；峰值及每活动面积峰值随时钟改变。**不再把“部位峰值之和保持原值”当作守恒项，峰值功率不是守恒量。**仍逐原胞检查燃料/水/面积/能量，单独记录峰值和旧时长的变化。各部位不同时引燃时，它们的峰值之和也不是实际同步原胞峰值。

每条规则必须提供`max_peak_hrrpua_W_m2_active`。反算峰值超过此输入时明确报错，不截断峰值、不删除燃料、不偷偷延长时长。**这是用户指定的情景一致性门禁；不是从文献确定的普适材料上限，也不是物理安全保证。**其面积分母是现有活动面积，不能与单位地表面积功率或单独量热试件峰值直接比较。

本次新增`component_curves_v3.py`及独立YAML契约`village-component-curves-1`，不修改旧部位配置schema。按`地类/部位ID`选择规则：分层地类使用声明的ID；未分层草地、灌木或林下可使用`whole`。未指定规则的部位保持继承曲线。即使地类在当前域不存在，也检查拼写是否匹配部位配置；不存在的合法地类报告`applied_nodes=0`。拒绝额外键、布尔数值、非有限/非法时长和无来源配置。证据标签是来源声明，不是自动证实其可靠性。

## 3. 合成输入为何保守标记

示例`component-curves.synthetic.yml`只对树下`surface_dead`和建筑`combustible_base`施加半时钟：

|部位|原g/s/d（s）|半时钟g/s/d（s）|半时钟总长度（s）|单位活动面积峰值（W/m²）|
|---|---|---|---:|---:|
|树下死燃料|120 / 140 / 600|60 / 70 / 300|430|300,000|
|建筑可燃基部|120 / 395.36 / 300|60 / 197.68 / 150|407.68|600,000|

只改变下部曲线，上部、草地和最初点火的灌木曲线不改；这使首次传播到下部的路径仍可对照。半时钟对应两倍峰值，双时钟对应一半峰值。400,000和700,000 W/m²的门禁同样是合成假设。430 s不是文献支持的细燃料驻留时间建议，只是原时钟的受控敏感性扰动。

另检查30 s压力输入（g=2、s=10、d=18）：原合成树下可热解燃料2.52 kg、能量45.36 MJ、活动面积0.63 m²，反算约3.66 MW/m²活动面积，超过400 kW/m²的合成门禁，故拒绝。**不能因此断言现实不可能出现此功率；它提示当前燃料分配、活动面积、完整燃烧能量与短时曲线假设需要共同核查。**只缩短时长而不检查峰值，会掩盖这种关系。

## 4. 固定实验与结果

脚本在求解前保存比较规则：8个合成场景×3时钟×2步长=48次；直接树下点火的仅辐射对照6次；同一高友村289格裁剪×3时钟×2步长=6次，共60次。合成截止1200 s、裁剪600 s，dt=0.5/0.25 s。几何图在所有时钟间逐数组相同；含水率、燃料、阈值及传输配置保持。没有为获得阳性结果降低引燃阈值，也未把极干活冠层加入本轮。

|---|---:|---:|---:|
|草地→首个树下部位引燃（s）|54.0|54.0|54.0|
|草地→第二个树下部位引燃（s）|178.83|134.50|265.00|

基部原胞属同一个建筑ID145，不能解释成5栋建筑损失。固定截止时间内消耗量可不同：双时钟节点尚未燃尽不代表燃料缺失；各已释放热量与实际已消耗燃料仍闭合。上述比较是指定曲线的**联合时钟敏感性**，增长速率、峰值、接触活动份额和加热持续时间同时变化，不能单独识别“峰值增加”这一因素的贡献，更不是现实传播速度验证。

30组时间步比较的引燃掩膜全部一致，首次引燃时间最大差1.25 s，小于预先保存的2 s标准；源能量账目最大误差约2.27×10⁻⁵ J，小于10⁻³ J标准。两类负对照通过；道路控制不代表有飞火情况下的防火线有效性。

## 6. 更值得做的下一步

**优先调查细燃料库存及有效面积，再拟合时钟。**目前“树下死燃料”来自原等效树木死燃料的比例分配，并不等于实测草/落叶/松针库存。应明确细/粗燃料、活死比例、干基水分、燃烧实际涉及质量、有效面积及冠层底高；建筑基部需明确木材、杂物或其他可燃物，不把砖墙本体设成燃料。测量HRR时序、累计释放热量、剩余炭与未燃料、火焰驻留时间，区分其定义；先单部位试验，再对未用于拟合的相邻燃料传播/墙体受热案例验证。

当前E=m_pyro H是指定燃烧参与量的可用能量闭合，仍假设参与燃料按给定曲线释放全部预算；没有燃烧中的含水率抑制、氧气受限、炭形成、阴燃、HRR反馈或外部熄灭。本次峰值改变也没有同步改变静态火焰高度/半径。固定Tg/h接触闭合的活动份额使用Q/Qpeak，因此不能把所有加速都解释成辐射峰值提高。

下一实现应先把实际受体朝向、相邻部位有限面可见性、墙体/地形遮挡接入同一预算，再以有适用域的动态火焰长度/倾斜模型耦合HRR与风。时钟标定与几何/热输运参数必须分别验证，避免用错的燃烧曲线补偿错的受热几何。三层辐射需先处理中间层透射/遮挡；旧网页部位展示仍待实现。灾前防火线优化继续后置，不能用当前三组合成曲线比较宣称真实防火线最优宽度。
