# 基础火灾模拟器：当前开发范围

2026-10-05用户明确要求优先简单、可用的火灾原胞自动机，完成传播、点燃、材质燃烧/燃尽和热量传递。该要求取代此前将动态火焰几何、风及有限面精化作为完成前置条件的排序。

当前主线使用已有 V3 单状态原胞：每格一个材料类别，自动取材质默认初始水分；近邻火焰接触与已有辐射边共同传热；到达引燃条件才转为燃烧；燃料消耗至零后燃尽并停止释放热量。不新增用户必须填写的几何、水分或分层参数。风场、部位分层、有限面和动态图保留为可选研究，不继续扩大基础模式依赖。

## 四项功能及规则

1. **传播**：燃烧格向周围传热；相邻格是否着火由其受热和材质决定，不强制所有邻居立即点燃。
2. **点燃**：达到材质引燃温度且完成内部有效水分的加热/蒸发条件后着火。初始水分来自材质默认值，不需逐格输入。
3. **燃烧与燃尽**：使用规定增长、稳定、衰减曲线；积分热量与可燃干质量×热值闭合。剩余燃料不增加、不小于零；燃尽后热释放归零。
4. **热量传播**：已有辐射加受有限源预算约束的近邻接触，并扣除表面散热。未到引燃条件的格可以升温而保持未燃。

保留现有公式，不以概率增益或修改材质水分来人为确保传播。用户界面主要操作仍是材质地图、起火点和模拟时长。简单模式不表示所有植物和建筑的点燃速度相同；草地比树木等效燃料更快，是当前参数下允许的行为。

## 一键基础验收与回放

```sh
.venv/bin/python examples/village/vegetation_v3/audit_core.py \
  --output runs/core-demo
```

脚本只调用既有基础求解器与材质库，生成6个可重算案例及网页回放：

| 案例 | 检查内容 |
|---|---|
| grass_chain | 草地依次引燃、消耗燃料、全部燃尽 |
| shrub_chain | 灌木依次引燃及燃尽 |
| tree_chain | 树木等效燃料较慢的传播与长时间燃尽 |
| vegetation_to_building | 灌木引燃0.2 m高可燃建筑外部受体 |
| inert_gap | 本合成案例道路格不燃、后方草地不被点燃 |
| heat_without_ignition | 提高目标引燃阈值的对照，升温但不点燃、不消耗其燃料 |

每个案例输出`case/`、`run/viewer/`，总报告为`acceptance.json`。检查燃料单调、惰性材质不燃、燃尽后停止释放热量，以及燃料/辐射/接触能量预算。阈值对照的2000 K为明确的测试条件，不是草地的现实参数。建筑案例0.2 m受体代表低处可燃外部部分；一格燃尽不等于整栋房屋倒塌或毁坏。道路对照不能证明任何宽度道路都能阻挡辐射或飞火。

启动简单交互演示：

```sh
.venv/bin/pyfireca village simulate-v3 runs/core-demo/grass_chain/case \
  --initial-run runs/core-demo/grass_chain/run \
  --output-root runs/core-interactive --port 8849 --no-browser
```

在网页选择起火格和时长，查看火灾状态、温度及剩余燃料即可。已有地图案例也可以用相同命令加载，不要求先实现风或精细包络。
