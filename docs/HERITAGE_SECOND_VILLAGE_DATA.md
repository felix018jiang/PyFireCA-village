## 本轮实际验收结果

统一影像/建筑/材料/核心输入、全947候选有界求解、两次原生/剪枝验证、冻结五栋后4个新屋面点×两臂×双尺度16次确认、地图/清单/代价导出均完成，总66次CA。五栋B0119＋B0165＋B0167＋B0177＋B0190、995.481072 m²在设计和新源的三核心检查全部通过；无拆除新鼓楼源在1 m下1169.36 s引燃，五栋同源双尺度均保护。上述迁移阶段数量界为2—5。随后[减拆续轮](HERITAGE_PINGYAN_COUNT_EXTENSION_20261030.md)新增29次设计CA和1次原生恢复，排除剩17对两栋，当前数量界提高为3—5；三/四及更小面积五栋未决。平岩两轮累计96次CA（含原生/剪枝验证），当前不称最少五栋或经济最优。

B0036的新确认源B0039是单列60 m压力族；设计/确认基准均无该桥失效，保留这一覆盖事实。四个新落点不重复设计多边形，不据其结果重选方案。第二村落已完成数值方法迁移，逐栋实测材料、社区实施条件与经济资料仍按下节补充；材料与双尺度没有调整。见[完整结果](HERITAGE_FULL_SEARCH_AND_PINGYAN_20261029.md)、[地图](results/heritage-full-pingyan-20261029/strategy/strategy-map.png)与[拆除清单](results/heritage-full-pingyan-20261029/strategy/demolition-list.csv)。

## 通用第二村落验收顺序（平岩本轮已完成）

1. 核定遗产与禁拆ID，整理统一坐标影像、轮廓、材料绑定及资格清单，完成几何、来源和33项物理参数核对。
2. 声明完整合格候选集合、种子方案与求解预算，按当前双尺度和材料规则打通无拆除、初始可行方案及受限搜索；未找到可行解也保留失败，不能沿用岜团三个编号。
3. 对冻结方案采用未用于搜索的新建筑/屋面落点确认，逐核心、逐层保存全部结果及源替代事实，再与岜团按同口径比较。
4. 导出同样的地图、拆除/费用清单、保护结果和证明范围。已有输入基础与跨村保护有效性分别报告；经济结论等真实可比成本补齐后再形成。

当前平岩已完成以上四步的数值方法验收，岜团331候选与平岩947候选的有界搜索均已运行；大规模CA穷举与村外联合试验未启动。本轮达到预算与验收后停止，未知费用与未决最优性范围如实导出。高友盘点属于2026-10-24历史资料，不是本轮第三案例。
