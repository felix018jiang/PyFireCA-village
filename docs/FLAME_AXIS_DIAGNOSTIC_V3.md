本阶段新增 `flame_geometry_v3.py` 与 `inspect-component-flames-v3`。读取已有部位运行的 CSV、物理网格及 DEM，重建瞬时规定 HRR，输出风致倾角、轴向、质心和端点。**不重新执行热求解，不改变传播、接触、辐射图、水分或燃料。** W02 的动态传热边尚未完成。

## 为什么先验证几何

现有网页 HRR 是末次求解步的均值，不能当作瞬时质量燃烧率；燃尽帧也可能含前一个步长中的正 HRR。诊断使用保存的点火时刻、增长/稳态/衰减时间与峰值，重建二次增长—平台—线性衰减曲线，在记录的实际燃尽时刻截断。未点火、未来点火、年龄零、曲线结束及燃尽之后全部归零。没有额外消耗燃料。

`H = available_energy_J / initial_pyrolysable_fuel_kg`，`m_dot = Q_instant / H`；分母为可热解干质量，不能替换成含水总质量。另核查规定曲线积分与保存的 configured_curve_energy_J 一致，且不超过原可用能量。这里是对规定曲线的重建，不是对真实燃烧质量损失的测量，也未加入风对 HRR 的反馈。

[Finney & Grumstrup（2023）](https://research.fs.usda.gov/treesearch/67813)表明火线强度与火焰长度的关系受燃烧带深度影响。因此本阶段不把单格 HRR（W）直接代入火线强度（kW/m）的相关式，也不统一用池火公式预测草地、树冠与建筑的火焰长度。轴长和基部高度继续取保存的部位设定，明确为既有情景假设。

## 实现关系及单位

本阶段使用[Hu 等（2013）文中列出的 AGA 分段关系](https://doi.org/10.1016/j.fuel.2012.10.075)：

- `m_dot'' = m_dot / A_footprint`，单位 kg/(m²·s)。燃烧占地面积不是传热活跃面积。
- `U_c = (g m_dot'' D / rho_air)^(1/3)`，单位 m/s；`U* = U / U_c`。
- `cos(theta) = 1` 当 `U* <= 1`；否则 `cos(theta) = U*^(-1/2)`。theta 从竖直方向计。
- 轴单位向量为 `(sin(theta) e_downwind_x, sin(theta) e_downwind_y, cos(theta))`。
- 质心为基点加 `L/2` 倍轴向；端点为基点加 `L` 倍轴向。轴长 L 不等于竖直投影高度。

AGA 来自池火体系；[Thomas 等（1963）](https://publications.iafss.org/publications/frn/516/-1)讨论木垛火的风致几何关系，但其关系不等于本模块的 AGA 分段式。这些研究不构成植被、树冠和建筑上的验证。弱燃烧末期在有限风下可能产生接近水平的倾角，是模型适用性问题；不得通过无证据的截角或最低 HRR 阈值隐藏。真正接入传热前需检查低质量流率范围及实际火焰间歇性。

## 数据与使用

```sh
.venv/bin/pyfireca village inspect-component-flames-v3 \
  runs/component-viewer-gaoyou-20261005-a \
  --wind examples/village/vegetation_v3/w01-wind.synthetic.yml \
  --geometry examples/village/vegetation_v3/w02a-flame-geometry.synthetic.yml \
  --end-time-s 60 --sample-interval-s 10 \
  --output runs/flame-axis-diagnostic-example
```

风配置使用 W01 严格单位、网格北、u/v 插值和覆盖时间规则。几何配置必须显式指定参考高度、风速折减系数、空气密度、重力，以及每个可燃部位 ID 的占地面积和特征直径；每项带单位、证据级别与来源。参考高度必须与风数据相同。`U_flame = factor * U_reference` 只是有记录的情景折减，本示例 factor=0.4 为 synthetic，绝不是实测或通用的 10 m 风速转换公式。不把局部 DEM 高程当作气象参考高度。

首版按部位 ID 共享占地面积；`whole` 包含不同植被材质，示例统一的圆形占地只适合数值诊断。要研究真实地物，应改用材质/部位或逐节点、方向相关的几何数据。特征直径 D 与面积分别显式给出，不隐式要求全部源为圆形，也不从照片自动推断。合成示例用圆形以使二者一致。

坐标使用物理格中心：x 向网格东、y 向网格北，行增加向南；z 为保存 DEM 加部位基部高度。没有 DEM 的案例使用原案例的平地假设。本阶段不求解坡地风场，也不让倾角沿坡旋转。

输出 `manifest.json` 与 `flame_axes.csv`。清单明确记录 `thermal_solver_executed=false`、`wind_coupled_heat_transport=false`、全部输入哈希、风/几何证据与限制。非活跃源无方向、质心和端点，CSV 对这些量留空；不留竖直“幽灵火焰”。模块输出数组只读。重复 YAML 键、旧边风模式、参考高度不符、缺失占地、非有限数、下溢/溢出、索引/网格不一致、燃烧曲线能量不闭合均拒绝。

默认最大200,000条节点×时刻记录，计算前检查；这不是精确内存上限。长时间、高密度采样应降低记录量。输出目录已存在则拒绝覆盖。诊断不要求网页回放或重建有限面图。

## 下一阶段的收敛条件

1. 先把任意轴向的圆柱表面及法向作严格旋转，验证零倾角与原有限面图一致、旋转对称、真实相交与遮挡；不可仅平移旧点源或乘一个顺风增强系数。
2. 明确固定原辐射份额与改变可见几何之间的能量闭合；接受份额超过1时不能通过归一化掩盖几何/积分错误。
3. 使用步内积分与风序列节点处理动态几何；不能把步末瞬时倾角直接配给整步均值 HRR。须做时间步及积分阶数收敛。
4. 接触传热另行检查倾斜火焰是否真正到达受体、与建筑/地形的阻隔及非辐射源预算。辐射改善不能自动代表接触改善。
5. 单株/燃料床风实验校核之后，再比较顺逆风、不同燃烧带尺度、树下—上层及植被—建筑传播。数值通过不等于实测标定。

## W02-b：旋转有限面的基础实现

`oriented_flame_surfaces_v3.py`现提供严格的右手旋转矩阵及`oriented_segmented_cylinder`。将受体与遮挡矩形先转入火焰局部坐标，再计算临界轴向分段；随后把闭合圆柱侧面/端盖的积分点和法向转回世界坐标，保留面积权重。不会只平移质心，也不会沿用未旋转的高度分段。圆柱绕自身轴的滚转无物理意义，但有限阶积分存在滚转误差；默认确定性基向量固定积分相位，数值阶数仍须收敛。

初始26项测试核对零倾角逐数组完全等于旧分段圆柱、0–180°轴向的总面积/法向/长度、含矩形遮挡的整体刚体旋转不变性、倾向近处受体的份额变化、输入/资源限制，以及3/6/12/24阶无遮挡倾斜积分。示例份额依次为0.0501032971、0.0500069021、0.0500051457、0.0500050779；12与24阶相对差约1.36×10⁻⁶。这里只是一个收敛案例，不能代表全部近场/遮挡几何都已收敛。

这个模块提供旋转源表面与连续矩形相交检查，**没有接入动态热求解，也未完成地形体积/源与源相交门禁**。目标和遮挡矩形必须是有限正尺寸、正交单位基。接入真实图前必须补地形体积策略、遮挡相关数值收敛与源预算，不能仅凭这个积分点生成器声称动态风场传播完成。

正式诊断使用`runs/flame-axis-diagnostic-20261005-f/`和`...-g/`：保存Python源码快照和哈希；a–e为此前阶段输出，不作为最终源码版本证明。检查记录为`runs/flame-geometry-validation-20261005.json`。


## W02-c：连续矩形与倾斜火焰圆柱相交门禁

`rectangle_intersects_oriented_cylinder`在火焰局部轴坐标中，将矩形按轴向[0,L]裁成凸多边形，连续求径向距离的最小值：边上精确极小值，加满秩情况下的内部驻点。亏秩情况下极小值线穿过边界，边极小值已覆盖。保留退化接触线/点，覆盖端盖和侧面相切；1e-12 m接触容差与旧竖直门禁一致。不会依赖矩形角点或固定采样网格。

表面生成器现在对受体及遮挡矩形先执行此门禁，相交/相切即拒绝。这是为了避免重叠表面导致辐射积分失效，不表示真实受体不能被火焰接触；真实接触属于下一阶段的非辐射传热与几何处理，而非继续对相交面计算这套有限面辐射。

新增14项测试：中部穿越且四角外部、端盖/侧面接触、分离、刚体旋转/投影大坐标平移、24种旧竖直矩形对照、受体/遮挡门禁，以及150个固定种子随机斜矩形检查，确认有实际采样落在圆柱内部时连续判定不会漏报。随机采样是附加查错工具，不是算法定义或完整证明。W02-b/c共40项，与轴诊断33项合计73项新增测试。

地形列是体积，不能只判断地形表面矩形是否穿过火焰：火焰完全埋在柱体内部时也要拒绝。该体积问题、源之间的遮挡/相交、动态能量预算与时间积分仍未完成。最终两份f/g诊断3024条记录、7条活跃记录；最大倾角约85.65°来自本例合成占地/折减与AGA近似，不能解释为当地真实火焰观测。
