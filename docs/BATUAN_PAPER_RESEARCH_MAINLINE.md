## 研究判断与中心命题

保留现有元胞自动机作为快速方案评价器，以模拟驱动的空间优化寻找防火布局，方法方向成立。论文应围绕一个清楚的问题展开：**在木质民居和重要遗产建筑达到给定保护目标时，怎样用尽量少的空间干预阻断山林—村落—建筑之间的传播链，并把个案优化结果转化为有适用条件的配置准则？**

建议题目：**面向木质传统村落的保护约束防火网络优化与配置准则：基于林地—建筑耦合元胞模拟**。如后续证据仍集中在单村，则题目采用“防火布局优化方法及岜团村验证”，将配置准则作为下一阶段成果。研究的价值由保护能力、减少占地、机制解释和跨情景迁移共同支撑，不由使用CA或迭代次数本身决定。

卫星图生成材质是该研究的测量与建模入口，防火布局是决策输出。若材质生成尚采用RGB推测，不把它包装为已经完成的新视觉算法；保留人工建筑标注和调查属性作为高可信输入。只有当分类方法有独立标签、基线、泛化和下游决策证据时，才将其提升为另一篇独立算法论文。

## 问题形式：先满足保护要求，再减少占地

令 \(x\) 是一组带宽的折线路径，\(s\) 是起火、天气、含水率等情景，\(H_s(x,T)\) 与 \(B_s(x,T)\) 分别为时限内引燃民居数与风雨桥数。

\[
\min_{x\in\mathcal X}\ A_{\mathrm{clear}}(x),\qquad
\text{s.t. }H_s(x,5400)=0,\ B_s(x,5400)=0\quad\forall s\in\mathcal S_{\mathrm{train}}.
\]

\(A_{\mathrm{clear}}\) 是允许区域内实际清理可燃地表的并集面积，不是线长乘宽的简单累加，也不含建筑删除。\(\mathcal X\) 显式限制保护建筑、起火格、评价边界、带宽、路径数和单路径长度；真实道路、坡度施工限制与遗产保护边界将在调查后加入。

本轮以字典序求解：最差情景引燃结构总数 → 平均结构总数 → 最差桥数 → 最差民居数 → 平均引燃建筑覆盖面积 → 最早结构引燃时间取负 → 实际清理面积。前两项包含民居与桥，因而不会为了省地接受桥引燃。零损失方案之间前六项完全相同，直接比较面积；若没有找到满足约束的方案，输出“尚未找到可行解”及当前最好不足量，不宣称达到保护目标。

90分钟是本轮声明的评估要求，不能直接当作通用防火标准。后续应结合持续外部暴露、应急处置时间和燃料耗尽过程确定适用时限。内部起火研究中，预设已经燃烧的房屋应事先从“新增引燃”统计中排除，其余保护对象集合固定；不能要求起火房屋同时从未引燃。

## 算法最重要的六部分

1. **带证据的空间属性生成。** 卫星影像、人工轮廓、DEM、道路及调查资料统一投影和栅格化；保留混合覆盖、材料属性来源与识别不确定性。建筑识别误差、窄巷和地表通道误差要通过下游方案变化评价。
2. **可检验的林地—建筑传播评价器。** 同步推进受热、蒸发、点燃、有限燃料释放与耗尽；保留近场接触和跨带辐射。区分受热、引燃、燃尽。当前村落评价器无动态风与飞火；若要支撑山火设计准则，这两类暴露与模型标定是下一阶段核心工作。
3. **受现实约束的干预表达。** 当前以有宽度折线的并集生成清理比例，建筑不删除，重叠不重复计地。下一步将道路、溪流、裸地等既有间断及可治理区域作为路由条件；村内建筑防火改造应有独立作用模型，不能将清理绿化等同于建筑防火隔离。
4. **保护优先的空间搜索。** 同时调整位置、方向、宽度、端点、转折点和多条带组合；束搜索保留多种候选，局部模式搜索缩短/减宽并检验，停滞后减小步长。当前方法是无梯度启发式，有搜索范围和计算上限，无全局最优证明。未来比较GA、CMA-ES/贝叶斯优化等时，以同样评价预算和多随机种子比较，避免只更换名称。
5. **独立的验证与不确定性检验。** 固定源代码、输入、情景和参数；训练选线冻结后才看留出结果；全网格复核裁剪误差。更不利参数、未见火源、风况和村落用于检验，不挑选其中最漂亮的结果作为结论。代理加速如果接入，最终选线仍交给原始评价器复算。
6. **从解到准则的提炼。** 对村落密度、建筑间距、地形、林缘暴露、燃料水分和风况分层；记录达到保护目标所需带宽、退距、连续性、依托既有间断比例和内外分配。以可解释模型提炼条件规则，再在留出村落中直接按规则布线检验；不在同一个村落拟合并验证“通用标准”。

## 易引燃性怎样处理更有说服力

原始案例不改。增加事先固定的5%引燃温升扰动：

\[
T_{\mathrm{ign}}'=T_{\mathrm{amb}}+0.95(T_{\mathrm{ign}}-T_{\mathrm{amb}}).
\]

只影响模型内可燃材料的引燃温度；燃料量、含水率、蒸发项、热值、热释放曲线及传热方式保持一致。**这不是引燃概率增加5%，也不是全部引燃能量恰好降低5%。** 基准版与扰动版均包含无干预和所有冻结方案，公开全部对照；本轮扰动结果不反馈选线。5%先作为敏感性假设，不能写成实测参数或已完成校准。

如果研究最终包含更易燃的干燥状态，应优先通过有来源的木材/植被水分、点燃温度和暴露试验校准，采用事先定义的合理区间。若扰动使方案失败，应报告安全裕度和适用边界，或在下一份预先登记的协议中将该工况纳入稳健优化。提高论文说服力的关键是对合理不确定性的保护能力，而不是为制造更大效果调整燃烧参数。

| 模型验证 | 求解器是否能评价关键传播及跨带失效机制 | 单元机理、材料试验/有来源参数、代表组团的独立物理对照、网格/时间步与辐射距离收敛 |
| 优化效果 | 能否在相同保护要求下更节省空间 | 无干预、历史选线、统一宽度、等距布线、随机/贪心和匹配预算优化；分直线/折线/多带统计 |
| 机制分析 | 效果来自何处，何时需要折线、多带或建筑改造 | 保护链路、跨带热暴露、端部绕行和既有间断；几何表达、接触、辐射、飞火及置信度模块消融 |
| 设计准则 | 个案方案能否转化为可迁移的设置方法 | 多村落、多来火/风况/水分；训练外规则应用；失败边界、最小需求与安全裕度 |

核心主图建议按“真实村落输入 → 保护约束自由几何搜索闭环 → 不同线形的可行域与面积 → 跨情景配置规律”组织。新算法机制图不能继续用代表24候选枚举的旧图。结果图应同时列民居和桥，不用总燃烧格数替代保护目标，也不预设折线一定优于直线。

优先补充的证据顺序：**材料/点燃依据与跨带机制验证 → 多来火方向及动态风/飞火 → 实测可治理区域与内部建筑措施 → 多种子/同预算算法比较 → 跨村落迁移和准则提炼**。影像分类误差敏感性与这些阶段并行开展。顶级期刊的目标应是有证据的新设计知识和可复用方法；当前单村静风案例是研究闭环的第一轮验证，增加计算量不能替代这些证据。

## 保护对象覆盖核对

本轮另存 `protection-coverage.json`：333个人工轮廓在5m网格中形成331个单一建筑归属；B0086基本被B0051包含，B0149基本被B0031包含。两处轮廓与网格相交的面积全部落在已有建筑格内，没有作为空地丢失。因此所有建筑格均未引燃时，零引燃目标也覆盖其空间；但逐栋损失计数不能据此区分嵌套对象，需核对人工标注包含关系。后续保护对象、房屋数量和材质统计均应沿用这一显式覆盖审计，避免把标注数量与元胞归属数混为一谈。

## 把算法贡献进一步收紧的方向

如果以高水平方法论文为目标，建议将下一阶段核心集中到**传播通道反馈驱动的内外协同防火网络设计**：先由多情景无干预模拟识别主要来火通道、最早受威胁建筑及关键结构间传热链；沿实测可治理空间生成连续走廊；在每次失败后定位“端部绕行、清理不连续、跨带辐射、飞火落点或建筑级联”中的具体原因，据此修改路径和防护层级，再做满足保护约束的面积压缩。这样，方案变化由可解释的传播机制引导，而不仅是通用随机变异。当前程序已有通用几何搜索基线，尚未实现上述热通道归因、动态风/飞火和机制引导路由，不能将它们写成已完成贡献。

村外与村内两个分支也应通过传播机制区分：村外降低外部火前沿对村落的暴露；村内抑制已经进入村落的结构间级联传播。前者的输出可以是依托道路/溪流/裸地的清理网络，后者还需要不可拆除建筑条件下的立面/屋面治理、局部隔离或其他有依据的措施。最终“设置标准”的研究产出应是**给定风、燃料水分、坡度、林缘暴露、建筑间距与保护等级时，选择布局类型和最小需求范围的规则及失效边界**，而不是从一幅村图推出一个统一带宽数值。
